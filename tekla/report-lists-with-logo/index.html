Material, Bolt and Shipping Lists With a Logo

Running the lists takes a minute. Getting the company logo onto them depends on one distinction: textual templates hold text, graphical templates hold pictures.

A Question

“How do we generate a material list, a bolt list and a shipping list with our company logo on them?”

Also asked as

  • How do I create a bolt list or a material list in Tekla Structures?
  • How do I put our company logo on a report?
  • My logo will not appear in the report I edited.
  • Where are the report files saved after I create them?
  • Is there a standard shipping list template, and what if there is not?

Generic form of a real customer question — names, company and project details removed. Tekla Structures 2026.

B Short Answer
Short answer

A logo needs a graphical template. A plain text report cannot carry an image.

The lists themselves come from the standard templates on the Drawings and reports tab.

  1. On the Drawings & reports tab, click Reports.
  2. Pick a material, bolt or assembly template from the list.
  3. Click Create from all, or Create from selected.
  4. For a logo, open Template Editor and click File, then New.
  5. Choose Graphical template, then click Insert, then Picture.
  6. Save it with the .pdf.rpt extension in your template folder.

Reports are saved in the Reports folder under the model folder by default.

Issue Summary

There are two questions hiding inside this one, and they have different answers. Producing a material list, a bolt list or a shipping list is easy and takes about a minute. Getting your company logo onto them is a template question, and the answer depends on a distinction that is easy to miss.

Tekla Structures has two kinds of template. Textual templates, with the file extension .rpt, contain text only. Graphical templates, with the extension .tpl, may contain text, graphics and bitmaps.

That single sentence settles the logo question. The standard reports most offices run are textual templates, and no amount of editing will put a picture into one. A report with a logo has to be built as a graphical template, which in report form means a PDF report template.

The same rule catches font choices too

You can use various font types in textual templates, but they do not appear in the output. If you want specific fonts in the output, you have to use a graphical template even if the template contains only text. A report that has to look like company stationery is a graphical template, always.

The Three Lists You Asked About

MATERIAL

Material list

One of the standard uses named in the documentation: material lists of construction assemblies. Run it from the Reports dialog against the whole model, or against a selection when you only want one area or one phase.

BOLTS

Bolt list

Also standard. Tekla Structures creates reports directly from the model database, so the bolt list reflects the bolt assemblies actually placed, not a separate schedule someone maintains by hand.

SHIPPING

Shipping list

Tekla Structures ships a large number of standard report templates, and which ones you have depends on your environment. Open the Reports dialog and read the list before assuming you need to build one.

IF MISSING

Building a shipping list yourself

If your environment has no shipping template, the usual approach is to start from an assembly report and group it by whatever your office uses for delivery: phase, lot, or an Organizer category. Copy an existing template rather than starting from a blank page.

SCOPE

All objects or selected objects

The Reports dialog offers Create from all and Create from selected. A shipping list is nearly always a Create from selected job, because a delivery is a subset of the model.

ACCURACY

Number before you report

Reports read the model database, marks included. An unnumbered or half-numbered model produces a list that looks complete and is not.

Creating a Report

  1. 1

    Open the Reports dialog

    On the Drawings & reports tab, click Reports.

  2. 2

    Choose the template

    Select the report template you want from the list. For an assembly report, you can produce a list of assemblies, or a report of the parts included in the assemblies.

  3. 3

    Decide the scope

    Click Create from all to report on every object in the model, or select objects in the model first and click Create from selected.

  4. 4

    Choose how it is shown

    Use Show report to display the result, and Print to send it to a printer. Reports can be shown On dialog, in a new window inside Tekla Structures, or With associated viewer, which opens an HTML report in a browser, for example.

  5. 5

    Know where the file went

    By default, reports are saved in the \Reports folder under the model folder. Reports can be created in .xsr, .html, .csv and PDF formats.

  6. 6

    Reopen an old one

    Open the Reports dialog and click Show to display a report you created earlier, or browse to the Reports folder directly.

    Reports do not refresh themselves

    A report is a snapshot taken when you ran it. Change the model and the report on disk still shows yesterday numbers. Recreate it after every change that matters, and put the date in the file name so nobody works from a stale one.

Putting the Logo On

The logo lives in a graphical template. For a report, that means creating a PDF report template.

  1. 1

    Open Template Editor

    On the File menu, click Editors > Template editor.

  2. 2

    Start a graphical template

    Click File > New and select Graphical template. Starting from a copy of a template that already produces the list you want is faster than building the data rows from nothing.

  3. 3

    Set the page size

    Click Edit > Properties and set the page size, such as A4, to match the output size you want. The size has to correspond to the sizes defined in the PaperSizesForDrawings.dat configuration file.

  4. 4

    Register the image folder

    Click Options > Preferences, go to the File Locations tab, and on the Symbols, pictures row add the folder holding your logo, separated by a semicolon.

    Tekla Structures looks in the model folder first, then in the symbols folder in the current environment. A logo anywhere else has to be registered here.

  5. 5

    Insert the logo

    Click Insert > Picture, select the file in the Select Picture File dialog, and click OK. Define the insertion point by clicking twice for opposing corners, or by dragging and releasing.

    Supported formats include BMP, GIF, JPG, PNG, TIFF and others. Keep the file small, because very large images update very slowly.

  6. 6

    Add the data rows

    Add rows with Insert > Component > Row, then place value fields with Insert > Value Field and pick the attribute from the Select Attribute dialog. This is where the material, bolt or assembly information comes from.

  7. 7

    Save it as a report template

    Click File > Save as and save with the file name extension .pdf.rpt, then copy the template to your template folder. It then appears alongside the other templates in the Reports dialog.

Making It the Company Standard

A template that lives in one model folder is a template you will rebuild. Textual and graphical templates, except mark templates, can also be read from the XS_FIRM or XS_PROJECT folders, so put the finished ones there.

The ready-made templates that came with your installation sit in the environment folders, under the system folders defined by the advanced option XS_SYSTEM. Copy one before you edit it, and give the copy your own name. Editing the shipped template directly means losing your work at the next upgrade.

Put the logo image itself somewhere shared as well, and register that folder with the advanced option DXK_SYMBOLPATH in Tekla Structures so it resolves on every machine, not just the one the template was built on.

Test on another machine before you announce it

A template with a logo works perfectly for the person who made it, because the image happens to be on their disk. Open the report on a colleague machine before you tell the office it is ready.

If Excel Is Where the List Really Ends Up

Many offices take the list into Excel and format it there, logo included. That route avoids the graphical template work entirely, and Tekla Structures supports it directly.

Excel reports are created using .xlsx.rpt templates together with Microsoft Excel .xltx templates. The letterhead then lives in the Excel template, where whoever maintains your paperwork can edit it without opening Template Editor.

Two practical tips from the documentation are worth knowing when the columns come out wrong. If the report does not divide into cells properly, add \t between the text and value fields. For a .csv.rpt report, add the text sep=; on the page header row so Excel recognises the semicolon as the cell separator.
