The Sheet Metal and Plate Work Workflow

Cones, hoppers, rolled and double-curved plates, modelled in three dimensions and unfolded into flat patterns for the cutting table. Plus an honest line on what this is not.

B Short Answer
Short answer

Tekla Structures handles structural plate work rather than general sheet metal design.

Bent plates, cones and rolled plates are modelled, then unfolded into flat patterns.

  1. On the Steel tab, click Plate, then the bent plate command.
  2. For hoods, hoppers and cones, use Create stand-alone bent plate.
  3. For rolled and double-curved shapes, use Create lofted plate.
  4. Unfold the part in the single-part drawing properties.
  5. On the File menu, click Export, then NC files.
  6. Convert the NC files to DXF to drive the cutter.

Check unfold_corner_ratios.inp first, because it sets where the neutral line sits.

Issue Summary

This is the workflow where the honest answer has to come first, because “sheet metal” means different things to different shops, and Tekla Structures covers one of those meanings very well and another one not at all.

What it does cover is structural plate work: bent plates, cylindrical and conical shapes, hoods, hoppers, cones, transitions, rolled plates and double-curved plates, modelled in the structure, unfolded to a flat pattern, and sent out as cutting data for a plasma cutter or a profiling machine.

What it is not is a dedicated sheet metal product design package. There are no machine-specific bend tables per press brake, no ductwork libraries, no fitting catalogues for HVAC, and no thin-gauge enclosure tooling. If your work is ducting, cladding systems or consumer-product sheet metal, Tekla Structures is the wrong tool and knowing that today is worth more than a page of workarounds.

The line to check before buying

If what you fabricate bolts or welds into a structure and arrives as cut and folded plate, this workflow fits. If what you fabricate is a product in its own right, made on a press brake to its own tolerances, it does not. Test that against your own order book before committing.

What Tekla Structures Gives You

BENT PLATES

Cylindrical and conical bent plates

Created from two existing parts, or from two part faces. The parts must be contour plates, or beams whose profile is a plate, for example PL200*20. Enter one radius for a cylindrical plate, two for a conical one.

STAND-ALONE

Shapes with no input parts

Stand-alone bent plates need no input parts selected. They are the tool for modelling cylindrical and conical parts such as hoods, hoppers and cones, built from picked points and a bend height.

LOFTED

Rolled and double-curved plates

With lofted plates you can create rolled plates with varying shapes and plates with double-curved form. The shape comes from construction objects: line to line, line to arc, arc to arc, circle to circle, or polycurve to polycurve.

UNFOLDING

Flat patterns from the model

Unfoldings can be created from parts modelled as a polybeam, which includes both profiles and plates. Lofted plates unfold too, under conditions set out below.

CUTTING DATA

NC and DXF for the machines

NC files carry DSTV for plates, and NC files can be converted to DXF to drive plasma cutters and other cutting devices. In the converted DXF, superfluous information such as dimension lines is removed, leaving the cutting contour, hole positions and adjustable text.

EXTENSIONS

Plate Work Tools

The Plate Work Tools package on Tekla Warehouse adds Unfolded bent plate, which creates NC files with bent lines or unfolded plates in the model, and Unfolded bent plate drawing, which creates the unfolded single-part drawing with the bent line.

Before You Start

NEUTRAL LINE

Set the bend allowance before anything else

The unfold_corner_ratios.inp file defines the location of the neutral line when profiles unfold. It affects the flat patterns and the NC files. Get this wrong and every developed length you cut is wrong by a consistent amount, which is the worst kind of wrong.

PARTS

Bent plates need the right input

Contour plates, or beams whose profile is a plate. Chamfered or cut faces cannot be used, only side faces, and curved beams and deformed parts cannot be used at all.

LIMITS

There is no full circle

Tekla Structures does not support full 360 degree stand-alone bent plates. You can create 359 degree plates instead. Plan your cylinders around that rather than discovering it mid-model.

MODIFICATION

Direct modification needs to be on

Switch on the Direct modification switch before you start creating stand-alone bent plates, because that is how you adjust them afterwards.

EXTENSIONS

Install Plate Work Tools early

Download the Plate Work Tools installer package from Tekla Warehouse before you need it. The unfolded drawing extension works only on bent plates modelled using the Attach to part command, which is a modelling decision, not a later choice.

MACHINE

Ask the shop what it reads

DXF for a plasma table, DSTV for a beam line, or a drawing for a manual brake are three different deliverables. Confirm which before you promise anything.

The Workflow, Stage by Stage

  1. 1

    Set the unfolding rules

    Check unfold_corner_ratios.inp, which defines the location of the neutral line when profiles unfold, and therefore the developed length of everything you cut.

    Set the advanced options that control the unfolded drawing while you are there. XS_USE_OLD_POLYBEAM_LENGTH_CALCULATION and XS_CALCULATE_POLYBEAM_LENGTH_ALONG_REFERENCE_LINE should be FALSE. XS_DRAW_BENDING_LINE_DIMENSIONS_IN_UNFOLDING set to TRUE dimensions the bend lines, and XS_DRAW_ANGLE_AND_RADIUS_INFO_IN_UNFOLDING set to TRUE dimensions angles and radii.

    Prove the neutral line on one real part

    Model one plate, unfold it, cut it, fold it, and measure it. One afternoon of that is worth more than any amount of reading, because it validates the setting against your own machine and your own material.

  2. 2

    Model bent plates from existing parts

    On the Steel tab, click Plate > Create cylindrical bent plate or Create conical bent plate. On the bent plate toolbar, choose By parts to select two parts, or By faces to select two side faces.

    Enter one radius for cylindrical, two for conical. Leave them blank and default bend radii are applied. After creation the input parts no longer exist separately: they merge into the bent plate, which inherits its properties from the first part you selected.

  3. 3

    Model hoods, hoppers and cones

    On the Steel tab, click Plate > Create stand-alone bent plate. Pick the centre point for the first radius, the start and end points of the arc, the height of the bend, and a point defining the second radius against the plate preview.

    Bent plate properties include Name, Profile, Material, Finish, Class, Numbering series and the IFC export settings. Property files use the .bpl extension.

  4. 4

    Model rolled and double-curved plates

    Create the construction objects first, because the lofted plate shape is based on their geometry. Then on the Steel tab click Plate > Create lofted plate, and from the toolbar choose Use two construction objects or Use one construction object and a point.

  5. 5

    Unfold to a flat pattern

    In the Single-part drawing properties, click the View creation button and go to the Attributes tab to unfold the part in the drawing.

    Lofted plates only unfold in some cases

    The unfolding works for lofted plates which have been created from single geometry to single geometry, and for tangential polycurve lofted plates. A shape outside that will not unfold, and it is better to find out at the modelling stage than at the cutting stage.

  6. 6

    Produce the unfolded drawings

    Use the Unfolded bent plate drawing extension to create the unfolded single-part drawing with the bent line for selected plates. It works on bent plates modelled using the Attach to part command.

    The drawings show bent line angles, with a negative value where the plate folds up and a positive value where it folds down.

  7. 7

    Number, then produce the cutting data

    Number the model as usual, then on the File menu click Export > NC files and create DSTV for plates.

    The Unfolded bent plate extension can also create NC files with bent lines for selected bent plates, or create the unfolded bent plates in the model.

  8. 8

    Convert for the cutting table

    Convert the NC files to DXF to drive plasma cutters and other cutting devices. In the converted DXF files all superfluous information, such as dimension lines, is removed, leaving the profile cutting contour, the hole positions and text you can adjust.

    The conversion settings live in the tekla_dstv2dxf_<env>.def file used by tekla_dstv2dxf.exe. The DXF Export (ML184) component combines the NC Files and DSTV to DXF Converter extensions and can also generate a report csv file, using the predefined settings named CS_DXF_Export in both.

The Two Numbers That Decide Whether It Fits

Before committing a shop to this workflow, two things are worth testing rather than assuming.

Developed length. The neutral line position from unfold_corner_ratios.inp is a single setting applied to your unfolding. A shop working across several materials, thicknesses and tooling setups may need more variation than one file gives, and there is no per-machine bend table in the way a dedicated sheet metal package provides. Test against the plates you actually fold.

Geometry coverage. Cylinders, cones, transitions, rolled and double-curved plates are covered. Anything that needs a full 360 degree stand-alone plate, a chamfered or cut face as a bend input, or a lofted shape outside the unfoldable cases, is not. Those are documented limits, not bugs, and each has a modelling workaround that is better decided early.

Where This Sits Next to the Other Workflows

Plate work is rarely the whole job. It usually sits inside a steel job, which is why the numbering, drawings, reports and NC file stages above are the same ones on the steel workflow page.

The difference is what happens between modelling and the machine. On ordinary steel you model a member and cut it. On plate work you model a three-dimensional shape, unfold it into a flat one, and cut that. The unfolding step is the whole discipline, and it is where the accuracy is won or lost.

If your work is cold-formed purlins, rails or light gauge stud framing rather than plate, that is a different workflow again, driven by manufacturer component systems rather than by unfolding.
