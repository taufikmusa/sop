B Short Answer
Short answer

Steel work in Tekla Structures follows one order, and the order matters.

Model, connect, number, draw, then export. Numbering sits in the middle because everything after it depends on marks.

  1. Model the members using grids and the profile catalog.
  2. Add connections from the component catalog, or your own.
  3. Set the numbering series, then run Perform numbering.
  4. Create assembly and single-part drawings.
  5. On the File menu, click Export, then NC files.
  6. Export IFC for coordination with the other trades.

Finish the detailing and create drawings before producing the NC files.

Issue Summary

Structural steel is the workflow Tekla Structures is most often bought for, and it is the most linear of them. You model the frame, you connect it, you number it, you draw it, and you send machine data to the shop. Each stage feeds the next, and skipping ahead costs more than it saves.

The pivot in the middle is numbering. A part mark is not typed in, it is calculated, and drawings, reports and NC files all read from those marks. Everything upstream of numbering is geometry. Everything downstream of it is paperwork and production data that inherits whatever numbering decided.

So the practical version of “what is the workflow” is this: get the model and the numbering rules right, and the rest is mostly running commands in order.

Before You Start

SETUP

Environment, role and configuration

These are chosen at startup and they decide which catalogs, components and default settings you get. A steel shop running the wrong environment fights the software over profile names and connection defaults for the whole job.

CATALOGS

Profiles, materials and bolts

Confirm the sections and bolt assemblies you actually buy are in the catalogs before modelling. Adding them halfway through means revisiting parts you thought were finished.

NUMBERING

Agree the scheme before the first beam

Prefixes, start numbers and what counts as the same part are decisions for day one. Changing them once drawings exist moves marks the shop may already be cutting to.

STANDARDS

Put the office standards in the firm folder

Drawing layouts, title blocks, report templates, custom components and export settings are the same on every job. Kept in the firm folder, every new model starts with them.

SHOP

Ask the shop what it reads

NC data, DWG, PDF and IFC are different deliverables for different people. Find out which the shop floor, the fabricator and the erector each expect before you produce any of them.

MARKING

Decide pop-marks and contour marking early

Tekla User Assistance advises adjusting contour mark and pop-mark settings before numbering and drawing creation, because those settings affect what the parts look like downstream.

The Workflow, Stage by Stage

  1. 1

    Set up the model

    Create the model, set the grids, and load the drawing and part properties your office standardised. Work from the firm folder rather than rebuilding settings per job.

  2. 2

    Model the members

    Model beams, columns, braces and plates with the profile catalog. Get the geometry and the member sizes settled before adding connections, because connections react to what they are attached to.

  3. 3

    Connect the frame

    Use system components from the Applications & components catalog where they fit. Where nothing fits, model the detail by hand once and save it as a custom component so the next occurrence is a click.

  4. 4

    Set the numbering series

    Double-click a part to open its properties in the property pane, and under Numbering series set the part prefix, the assembly prefix and the start numbers. Put these in the default part properties so new parts are born in the right series.

  5. 5

    Number the model

    On the Drawings & reports tab, click Perform numbering > Number modified objects. Read the Numbering preview dialog before clicking Assign numbers.

    Number on a routine, not on an emergency

    Tekla User Assistance suggests numbering the model when you start your working day, or when you finish for the day. Marks refreshed daily never drift far from the drawings, and you notice a problem the day it appears rather than a week later.

  6. 6

    Create the drawings

    Create single-part and assembly drawings for fabrication, and general arrangement drawings for erection. For a whole job use the Master drawing catalog, which keeps four hundred sheets consistent instead of four hundred sheets nearly consistent.

  7. 7

    Run the reports

    Material lists, bolt lists and assembly lists come from Reports on the Drawings & reports tab, read straight from the model database. Number first, because a report of an unnumbered model looks complete and is not.

  8. 8

    Produce the NC data

    On the File menu, click Export > NC files. The documentation is clear about the order: complete the detailing and create drawings before producing the NC files.

  9. 9

    Hand over for coordination

    Export IFC for the other trades, and DWG for anyone who works in a drafting package. These are deliverables, not production data, and they carry only what your export settings include.

NC Files in Detail

This is the stage that turns your model into something a machine cuts, and it is where steel-specific knowledge earns its keep.

Tekla Structures produces NC files in the DSTV format, an industrial standard defined by the German Steel Construction Association. A DSTV file is a text file in ASCII format. Tekla Structures transforms the part length, hole positions, bevels, notches and cuts into sets of coordinates the machine tools can use to create the part in a shop.

  1. 1

    Open the dialog

    On the File menu, click Export > NC files.

  2. 2

    Load your settings

    Select predefined settings from the settings file list and click Load. Standardised settings in the firm folder beat re-entering them every job.

  3. 3

    Choose the file types

    Select the Create checkbox next to DSTV for plates, DSTV for profiles, or both.

  4. 4

    Edit the settings if needed

    Select an NC file settings row and click Edit.... The tabs are Files and part selection, Holes and cuts, Hard stamp and Advanced options.

    The Header... button customises the file header and can add text for individual parts using template attributes such as <<WEIGHT>>. Pop-marks... and Contour marking... have their own dialogs.

  5. 5

    Choose the scope

    Select All parts for the whole model, or select parts in the model first and choose Selected parts. The advanced option XS_DSTV_NUMBER_OF_PARTS_BY_SELECTION controls the number of parts reported in the file header.

  6. 6

    Collect the output

    Files are created with the extension .nc1, by default in the \DSTV_Profiles or \DSTV_Plates folder under the current model folder. Change this in the File location field on the Files and part selection tab.

    DXF is a separate step

    This dialog produces DSTV. Converting DSTV to DXF is done afterwards with the DSTV to DXF Converter tool, not by picking a different format here.
