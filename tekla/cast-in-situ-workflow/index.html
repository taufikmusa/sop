B Short Answer
Short answer

Cast in situ work runs on pour objects rather than on parts.

Pour management is switched off by default. Nothing below works until you turn it on.

  1. Set XS_ENABLE_POUR_MANAGEMENT in Advanced options, then restart.
  2. Set the concrete parts to Cast in place.
  3. On the Concrete tab, click Pour view to see pours.
  4. Use pour phases so unrelated parts do not merge.
  5. Add pour breaks to split pours into what you actually cast.
  6. Reinforce, then report volumes and formwork areas.

Parts that touch, share a material grade and share a pour phase merge automatically.

Issue Summary

Cast in situ is the concrete workflow where the thing you build and the thing you model are not the same shape. You model a column, a beam and a slab as separate parts because that is how you design and reinforce them. The site pours a lift, and that lift cuts across all three.

Tekla Structures reconciles those two views with pour objects. A pour object is a building object that consists of one or more cast-in-place concrete parts, or parts of them. Tekla Structures automatically merges multiple cast-in-place concrete parts into a pour object when they have the same material grade and pour phase number, and they touch or overlap one another.

A pour unit goes one step further: it is a pour object plus all related reinforcement, embeds and other objects that need to be in place before concrete can be poured on the building site. That is the real deliverable for a site team, because it answers “what has to be finished before the truck arrives”.

It is off until you switch it on

Pour management is disabled by default. It is enabled through Advanced options with XS_ENABLE_POUR_MANAGEMENT. If your Concrete tab has no Pour view and your parts refuse to merge, this is almost always why.

The Three Words to Learn First

Term What it is Why you care
Pour objectOne or more cast-in-place concrete parts, or parts of them, merged where they share material grade and pour phase and touch or overlap.This is what gets a volume. It is the shape of the concrete, not the shape of the design.
Pour unitA pour object plus all related reinforcement, embeds and other objects needed in place before the pour.This is what the site checks before pouring. It is the readiness list.
Pour breakA split that divides a pour object into smaller pour objects.This is how the model learns your construction joints and pour sequence.

Pour breaks can be added to pour objects or to concrete parts whose cast unit type is Cast in place. That restriction is the same rule that governs the precast side from the other direction: the cast unit type decides which tools will talk to a part.

Before You Start

ENABLE

Turn pour management on first

Set XS_ENABLE_POUR_MANAGEMENT in Advanced options and restart. Everything on this page depends on it, and nothing warns you that it is off.

TYPE

Set the cast unit type to Cast in place

Double-click a concrete part, go to the Cast unit section and choose Cast in place. Precast and cast-in-place parts cannot be mixed within a cast unit, and pour tools only work on the cast-in-place side.

PHASES

Plan pour phases before modelling

Parts merge into one pour object when material grade and pour phase match and they touch. Pour phase is the control you use to stop a column merging into a slab it is not poured with.

GRADES

Be consistent about material grade

Two parts poured together but modelled with different grades will not merge. Two parts with the same grade that should not merge will. Grade is doing structural and logistical work at the same time.

SEQUENCE

Get the construction sequence from site

Pour breaks encode the sequence. Guessing it and then correcting it later means revisiting quantities that people may already be ordering against.

REBAR

Decide the reinforcement method

Reinforcement components are the recommended first choice because they are adaptive and update when the part changes. Rebar sets cover the geometry components cannot.

The Workflow, Stage by Stage

  1. 1

    Enable pour management

    On the File menu, go to Settings > Advanced options and set XS_ENABLE_POUR_MANAGEMENT. Restart Tekla Structures.

  2. 2

    Model the concrete

    Model the columns, beams, walls, slabs and foundations as ordinary concrete parts, with the cast unit type set to Cast in place. Put that type into your default part properties so nothing is born wrong.

  3. 3

    Switch the view to pours

    Double-click the view to open View properties, click Display, make sure the Parts checkbox is selected, and in the Cast in place list select Pours. Click Modify.

    For a quick toggle, click Pour view on the Concrete tab to switch the active view between Parts and Pours.

    Continuous structures behave differently in part views

    Continuous concrete structures cannot be selected or highlighted in part views. If you are trying to select something poured as one piece and cannot, switch to the pour view rather than assuming the model is broken.

  4. 4

    Control the merging with pour phases

    Define pour phases to prevent unwanted merging of concrete parts. This is the difference between a model that reports your pours and a model that reports one enormous blob of concrete.

  5. 5

    Add the pour breaks

    Split pour objects into the pieces you will actually cast, following the construction joints and the sequence the site has agreed.

  6. 6

    Reinforce

    Use reinforcement components wherever they fit, since they are adaptive, attached to a concrete part, and updated automatically if the dimensions of the reinforced part change. Use rebar sets for geometry the components do not cover.

    Reinforcement modelled across several parts is one of the reasons the pour view exists: it lets you reinforce the structure as it is built rather than as it is drawn.

  7. 7

    Report the quantities

    Report pour information such as concrete volumes and formwork areas. These are the numbers that go to procurement and to the site, and they are only right once the phases and breaks are right.

  8. 8

    Draw and coordinate

    Produce the general arrangement and reinforcement drawings, run the bending schedules, and export IFC for the other trades.

Where This Meets the Other Workflows

Cast in situ rarely stands alone. A frame with precast planks, a bridge with a cast deck and precast beams, or a core poured on site with steel framing around it are all one model containing two workflows.

The dividing line is the cast unit type. Cast in place parts belong to pour objects and use the tools on this page. Precast parts belong to cast units and use the precast tools. Precast components cannot be applied to cast-in-place cast units, which is the software telling you the same thing.

Reinforcement is shared ground: the same rebar sets, shape catalog and BVBS export serve both sides, which is why rebar has a workflow page of its own.
