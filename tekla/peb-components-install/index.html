Installing PEB Components

Pre-Engineered Building tools are a Tekla Warehouse extension, not part of the installation. Here is the import route, the office-wide route, and how to check version support honestly.

“How do I install PEB components in Tekla Structures 2026? I cannot find them anywhere in the component catalog.”

B Short Answer
Short answer

PEB tools are not part of the installation. They come from Tekla Warehouse as an extension.

Sign in to Tekla Warehouse first, and check the version filter before you download anything.

  1. Search Tekla Warehouse for Pre-Engineered Building Tools.
  2. Pick a version listed as compatible with your Tekla Structures.
  3. Download the file, which is normally a .tsep package.
  4. Click Applications & components, then Manage extensions, then Extension manager.
  5. Click Import, browse to the .tsep file, and select your versions.
  6. Restart Tekla Structures.

After the restart the tools sit under Ungrouped items in the catalog.

Issue Summary

Pre-Engineered Building tools do not ship inside Tekla Structures. They are a separate collection of extensions published on Tekla Warehouse, and until you install them the commands simply are not there to find.

That is the whole answer to “where is PEB in 2026”. Nothing is hidden behind a role or a licence tier. The catalog is empty of these tools because nobody has imported them into this installation yet.

The install itself is short. The part worth slowing down for is compatibility: an extension built for one Tekla Structures version is not automatically valid for the next one, and Tekla Warehouse is the only place that tells you the truth about which versions a package supports.

What Is Actually in the Collection

MEMBERS

PEB Member

Creates built-up members with multiple depths, up to six, and multiple webs, up to five, plus flanges. This is the tapered rafter and column tool that most PEB work starts from.

MEMBERS

PEB Builtup

The other built-up member tool listed alongside PEB Member in the same collection of Pre-Engineered Building Tools.

CONNECTIONS

PEB Connections

Connection components shaped around common pre-engineered building practice, rather than the general-purpose steel connections in the standard catalog.

COMPONENTS

PEB Components

The wider set of PEB modelling components published in the same collection on Tekla Warehouse.

MAINTENANCE

PEB Member Updater

A companion tool for updating PEB members after changes, documented on Tekla User Assistance in its own article.

ENVIRONMENTS

Supported environments

The documentation for PEB Member lists Default, India, United States (Imperial) and United States (Metric). If your office runs a different environment, test before you commit a project to these tools.

Before You Start

ACCOUNT

You must be signed in

Tekla Warehouse requires a sign-in before it will let you download. Use the same Trimble Identity you sign in to Tekla Structures with.

VERSION

Check compatibility on the page, not from memory

Tekla User Assistance states the installers are for Tekla Structures version 21.0 and above, with older installers held separately. Whether a given package is published for 2026 is shown by the version filter on the Warehouse item itself, so read it there before downloading.

RIGHTS

Windows permissions

Extensions install into the Tekla Structures data folders. On a locked-down office machine you may need your IT administrator to run the import.

CLOSE FIRST

Plan for a restart

An imported extension is not live until Tekla Structures restarts. Finish and save what you are doing before you start the import.

ROLLOUT

Decide single machine or whole office

Installing one machine at a time is fine for a trial. For a team, the shared folder and central installation routes below save you repeating the same clicks on every desk.

MODEL

Test in a scratch model

Try the tools in a throwaway model before using them on live work, so you learn how the members behave without putting a live job at risk.

The Procedure

  1. 1

    Find the tools on Tekla Warehouse

    Sign in to Tekla Warehouse and search for the Pre-Engineered Building Tools collection. Read the item description and the supported version list before you go any further.

  2. 2

    Select a compatible version and download

    Select a version that matches your Tekla Structures version, then click Download. Tekla User Assistance is explicit about this point: ensure that you download a version that is compatible with your software version.

    What you get back depends on how the publisher packaged it. A .tsep file is imported through the Extension manager. An .msi or .exe file is run like any Windows installer. A .zip file is extracted first, then the installer inside it is run.

  3. 3

    Open the Extension manager

    Click the Applications & components button in the side pane to open the Applications & components catalog. Click Manage extensions > Extension manager.

  4. 4

    Import the package

    Click Import and browse to the location where you saved the .tsep file. Tekla Structures opens a dialog listing the installed Tekla Structures versions that are compatible with the extension.

    Select the versions you want the extension imported to, then click Import. If a version you expected is not offered, the package does not support it, and no amount of retrying will change that.

  5. 5

    Restart Tekla Structures

    Restart to complete the installation. The extension is shown in the Ungrouped items group in the Applications & components catalog.

  6. 6

    Tidy the catalog

    Move the extension into a more suitable group, or create a new group for it, so the PEB tools sit together instead of scattered among ungrouped items.

Installing for a Whole Office Instead of One Machine

Clicking through the Extension manager on twenty machines is a poor use of an afternoon. Tekla User Assistance documents two better routes.

Shared folder, per user: set the advanced option XS_TSEP_TO_BE_INSTALLED_ORG_DIR in user.ini to a shared folder path. Extensions dropped in that folder install automatically the next time each user restarts.

Central installation, all users: copy the .tsep files to the folder below. Tekla User Assistance recommends ROBOCOPY for copying these in bulk.

%XSDATADIR%\Extensions\To be installed

Either way, the extension installs itself on the next start rather than waiting for someone to click Import.

Where the Files Land, and How to Remove Them

Folder What is in it
%XSDATADIR%\Extensions\InstalledExtensions that are active and working.
%XSDATADIR%\Extensions\To be installedPackages staged for installation on the next start.
%XSDATADIR%\Extensions\Invalid installationsPackages that failed. Look here first when an extension never appears.
%XSDATADIR%\Extensions\Cancelled installationsInstallations that were cancelled part way through.

To uninstall, open the Extension manager from Applications & components > Manage extensions, select the extensions with Ctrl or Shift, click Remove, and restart Tekla Structures.

There is also a central route: create an empty file named RemoveExtensionOnStartup and copy it into each installed extension folder. Those extensions remove themselves on the next start.

An extension that never shows up is usually in Invalid installations

If the tools are still missing after a restart, look in the Invalid installations folder before reinstalling. A package that failed its compatibility check lands there quietly, without an error on screen.

Being Honest About Version 2026

Tekla User Assistance documents the PEB Member tool itself, and documents how any .tsep extension is installed into any supported version. What it does not do is publish a fixed statement that a 2026 build of the PEB collection exists.

That information lives on the Tekla Warehouse item page, where the publisher sets the supported versions, and it can change when a new build is released. Read the version list there. If 2026 is not offered, the honest answer is that the package has not been published for 2026 yet, and your local Tekla Support can tell you what is planned.

Do not force an older package into a newer version

The Extension manager only offers the versions a package declares. Working around that by copying files by hand produces tools that half work, and problems that are very hard to diagnose later.
