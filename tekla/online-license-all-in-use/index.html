Online License Locked on Another Device

Why Tekla Structures reports the subscription as unavailable or already in use, how the three-day reservation works, and how to release the license from the device that is holding it.

B Short Answer
Short answer

We have reset the license from our end, so you should be able to sign in again now.

An online license stays reserved on the last device it was used on for up to three days. While it is reserved, the same subscription cannot be used anywhere else.

To free it yourself next time, clear the reservation checkbox as you close Tekla Structures:

  1. Open a model and save your work.
  2. Close Tekla Structures.
  3. In the Exit dialog, clear the checkbox that keeps the license reserved.

Do this on every device you use, and in every version. Each version holds its own reservation.

Issue Summary

You cannot sign in and start Tekla Structures, or you are told that the subscription is already in use. In almost every case the license is not lost — it is still reserved on the last device it was used on, because the reservation checkbox in the Exit dialog was left selected when Tekla Structures was closed.

A reserved license is held for a maximum of three days. During that time the same subscription cannot be used on another computer. You can release it yourself from the device that holds it. If that device is out of reach, local Tekla Support releases it.

Before You Start

VERSION

Confirm the version

Check which Tekla Structures version you are on. The checkbox wording and where it lives changed at 2021, so on 2020 or 2019 you are looking for a different control entirely.

SCOPE

One subscription, one computer

A subscription can only be used on one computer at a time. The message is not a licence-count problem unless there are genuinely more users than seats.

TIMING

The three-day window

A reserved license is held for a maximum of three days. After that it frees itself, so if you can wait, no intervention is needed at all.

VERSIONS

Reservations are per version

If you run more than one version of Tekla Structures, each version holds its own reservation and each has to be released separately.

IDENTITY

Confirm the identity

Make sure you are signing in with the Trimble Identity the subscription is assigned to. A second identity will report no license rather than a reserved one.

ACCESS

Can they reach the other device?

The whole path forks here. If the reserving computer is reachable, you release it yourself. If not, local Tekla Support has to release it.

Why the License Looks Locked

CAUSE 1 · MOST COMMON

The checkbox was left selected

Closing Tekla Structures with the reservation checkbox still selected keeps the seat on that device. This is the ordinary cause and the one the short answer addresses.

CAUSE 2

Internet connection dropped

Lost or unstable connectivity while Tekla Structures was running can leave the seat held. The documented triggers include connection loss as well as the checkbox.

CAUSE 3

Two instances of the same version

Running more than one instance of the same Tekla Structures version is a documented trigger for the “All in Use” message.

CAUSE 4

Left idle for a long period

Software left unused for an extended period is also listed as a trigger. Restarting and closing cleanly is what clears it.

CAUSE 5

Released in one version only

With 2025 and 2026 installed you may have released one and not the other, and you will still be blocked on the version you did not release.

Resolution — Release the License from the Device Holding It

  1. 1

    Go to the device that holds the license

    The release happens on the computer where Tekla Structures was last used, not on the new one. If that machine is unavailable, skip to the section below.

  2. 2

    Open a model and save

    Start Tekla Structures, open a model, and save the work. The documented steps begin here rather than at a closed application.

  3. 3

    Close Tekla Structures

    Close the application normally so the Exit confirmation dialog appears.

  4. 4

    Clear the reservation checkbox in the Exit dialog

    Clear the checkbox that keeps the license reserved on the device, then let the application close. Selected keeps the seat; cleared releases it.

    The label is not the same in every version

    The published articles quote different wording for this checkbox — Yes, keep the license in the 2026 documentation, and Keep this license reserved on this device in the release-issues article. Go by what the checkbox does rather than by one exact label, or you may conclude it is not there at all.

  5. 5

    Repeat for every version installed

    Each version of Tekla Structures holds its own reservation. Release the license in each version you run, not only the one you are trying to start.

    The seat may still be held elsewhere

    If the subscription has been used on more than one machine, releasing it on this one is not enough. Every device that has run Tekla Structures with this subscription has to be closed with the checkbox cleared.

If You Cannot Reach That Computer

This is the case the short answer refers to. Tekla User Assistance is explicit that you should go to your local Tekla Support when the reserving computer is unavailable — there is no self-service release from your own online profile.

Ask support rather than guess

There is no documented way to release the seat from your own online profile. If the reserving computer is out of reach, the release is done by support. Have your Trimble Identity, the version, and the device name ready — that is what the reset needs.

Checkbox Wording by Version

The wording of the checkbox has changed over time, and the published articles do not all quote the same string. Go by what the checkbox does rather than by the exact label.

Version Wording / Where
2026The 2026 documentation quotes Yes, keep the license in the closing confirmation dialog. Clear it to release the seat.
2021 and newerThe release-issues article quotes Keep this license reserved on this device; the different-computers article quotes Keep my license reserved on this device for this version of Tekla Structures. Same checkbox, same effect.
2020Open a model and save, click the username, then clear Stay signed in before closing.
2019 and 2019iOpen a model, click the username and clear Stay signed in, then close Tekla Structures.

Stopping It Happening Again

If you move between machines regularly, the checkbox can be forced to default to cleared. This is an administrator change to a configuration file, not an end-user setting, which is why it is kept out of the short answer.

XS_DEFAULT_KEEP_ONLINE_LICENSE_CHECKBOX

    TRUE    The checkbox is selected, so the license seat stays
            reserved. This is the default.

    FALSE   The checkbox is never selected by default, so the
            license is released each time Tekla Structures closes.

    Not set The checkbox follows whatever was selected in the
            previous Tekla Structures session.

    Set it in an initialization file - user.ini,
    teklastructures.ini, or bypass.ini.
This one cannot be set from the Advanced Options dialog

XS_DEFAULT_KEEP_ONLINE_LICENSE_CHECKBOX must be set in an initialization (.ini) file — user.ini, teklastructures.ini or bypass.ini. Searching for it under File > Settings > Advanced Options will send you looking for something that is not there.
