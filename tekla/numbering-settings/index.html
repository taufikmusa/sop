Numbering Settings Before You Model

One model-wide set of rules decides what counts as the same part. Set it at the start of the job, not in the middle of it.

B Short Answer
Short answer

Numbering settings decide what makes two parts count as the same part.

Set them once at the start of a job. Changing them later moves marks that are already on drawings.

  1. On the Drawings & reports tab, click Numbering settings.
  2. Choose Compare to old, or Take new number for changed parts.
  3. Tick Re-use old numbers if you want deleted numbers back.
  4. Set the tolerance for how close counts as identical.
  5. Tick the properties that should affect numbering, such as holes and part name.
  6. Click OK, then run Perform numbering.

Leave Renumber all clear unless you truly mean to start over.

Issue Summary

Numbering settings are the rules Tekla Structures uses to decide whether two objects are the same object. Everything downstream depends on them: how many marks the job has, how many single-part drawings you produce, and what the fabricator ends up cutting.

There are two separate things people mean by “numbering settings”, and mixing them up wastes a lot of time. The numbering series, which is a prefix and a start number, lives on each part. The numbering setup, which is the subject of this page, is one set of rules for the whole model.

The single most useful piece of advice about this dialog is about timing rather than content. Adjust the settings early in the project, before you create drawings or reports, and do not change them in the middle of a project.

Opening the Dialog

On the Drawings & reports tab, click Numbering settings > Numbering settings. The Numbering Setup dialog opens.

This is a model-wide setting. Whatever you choose here applies to every part in the model, which is exactly why it deserves a decision at the start of a job rather than an adjustment halfway through.

The Main Choices

Setting What it does When to use it
Renumber allAll parts get a new number. All information on previous numbers is lost.Almost never on a live job. Read the warning below before you touch it.
Re-use old numbersTekla Structures reuses the numbers of parts that have been deleted.Keeps the mark range tight on a job with a lot of deletions. Risky once drawings and lists are in circulation.
Check for standard partsCompares parts in the current model to a standard-part model, so recurring parts keep a fixed number.Useful where the same catalogue items appear job after job.
Compare to oldThe part gets the same number as a previously numbered similar part.The stable choice. A modified part that matches an existing one falls back into that existing mark.
Take new numberThe part gets a new number even if a similar numbered part already exists.When a change has to be visible as a new mark on the shop floor, whatever it matches.
Keep number if possibleModified parts maintain their previous numbers if possible.The gentlest option for a job already in fabrication.
ToleranceObjects get the same number if their dimensions differ less than the value entered.Set it to the difference your shop genuinely does not care about, and no larger.
Synchronize with master modelUsed in multi-user mode for the save-numbering-save sequence.Multi-user models. It lets numbering be cancelled before the last save is made.
Renumber all is not an undo button

Tekla User Assistance states plainly that Renumber all permanently removes the existing position numbers, and that any existing drawings will also be removed. On a job with drawings issued, that is a very expensive checkbox. Leave it clear unless starting the numbering over is genuinely what you want.

What Makes Two Parts Different

The lower part of the dialog is a list of properties, each with a checkbox saying whether it affects numbering. This is where you tune how fussy the comparison is.

GEOMETRY

Holes

With this on, two otherwise identical beams with different hole patterns get different marks. Steel fabrication normally wants this on, because the holes are what the shop drills.

IDENTITY

Part name

Two identical plates called different things stay apart. Handy when the name carries meaning your shop relies on, and a nuisance when names are inconsistent.

ORIENTATION

Beam and column orientation

Separate settings for beams and for columns. Turn these on when a member that is handed or rotated must be treated as a different piece.

ASSEMBLY

Assembly name and assembly phase

Assembly phase is the usual way to keep marks from one delivery phase out of another, so phase two does not renumber into phase one.

CONTENT

Reinforcing bars and embedded objects

For concrete work. Two cast units with the same shape but different bar arrangements only separate if this is on.

FINISH

Surface treatment and welds

Two members that differ only in paint specification or weld detail stay together unless you switch these on.

The Procedure

  1. 1

    Agree the scheme before you open the dialog

    Decide with whoever runs fabrication what counts as the same part. Holes, finishes and handing are the three that cause arguments later, so settle them first.

  2. 2

    Open the Numbering Setup dialog

    On the Drawings & reports tab, click Numbering settings > Numbering settings.

  3. 3

    Set how modified parts behave

    Choose between Compare to old, Take new number and Keep number if possible. For most jobs, comparing to old is the setting that keeps marks stable across revisions.

  4. 4

    Decide about reusing and renumbering

    Set Re-use old numbers deliberately, not by accident. Leave Renumber all clear.

  5. 5

    Set the tolerance

    Enter the value below which two objects count as identical. Objects get the same number if their dimensions differ less than the value entered, so a generous tolerance quietly merges parts that your shop may consider different.

  6. 6

    Tick the properties that matter

    Work down the list of properties and switch on the ones that should force a different mark. Everything left off is a difference Tekla Structures will ignore.

  7. 7

    Save and number

    Click OK, then on the Drawings & reports tab click Perform numbering > Number modified objects. Check the Numbering preview dialog, then click Assign numbers.

  8. 8

    Write the settings down

    Record the agreed settings somewhere the whole team can see, and put the same settings into your firm folder so the next model starts from them instead of from the defaults.

Living With the Settings Afterwards

Build a routine around numbering rather than treating it as an occasional event. Tekla User Assistance suggests numbering the model when you start your working day, or when you finish for the day. Marks that are refreshed daily never drift far from the drawings.

If Tekla Structures warns about overlapping position numbers, deal with it immediately. Objects with overlapping numbers will not be numbered, so the warning is describing parts that currently have no mark at all. The Numbering preview dialog is where you find them.

Resist the temptation to use numbering as a filing system. Numbering is not just another way of classifying parts. To classify, use Organizer, user-defined attributes or colours, and leave the numbering settings to do the one job they are good at.

Multi-user models need one more decision

In multi-user mode the Numbering Setup dialog has a Synchronize with master model (save-numbering-save) checkbox. Agree as a team whether it is on, because half the team numbering one way and half the other produces conflicts that look like software faults.
