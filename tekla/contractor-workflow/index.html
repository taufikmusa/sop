B Short Answer
Short answer

A contractor uses the model to answer questions, not to fabricate from it.

The two tools that matter most are Organizer and reports. Both read the live model.

  1. Set up the building hierarchy: project, site, building, level, space.
  2. Use phases to group objects the way you build them.
  3. Open Organizer and build the location and custom categories.
  4. Use Object Browser to query quantities and export to Excel.
  5. Run the takeoff reports for the breakdown you need.
  6. Share through Trimble Connect for the wider project team.

Model the way you build: start at the lowest elevation and work upwards.

Issue Summary

A contractor asks the model different questions from everyone else. Not “what shape is this piece” but “how much of it is there, on which level, in which pour, and is it ready”. The geometry is a means to an end, and the end is quantities, sequence and readiness.

That changes which part of Tekla Structures you live in. A detailer lives in drawings and numbering. A contractor lives in Organizer and reports, both of which read the live model rather than a snapshot, and in Trimble Connect for getting that information to everyone else.

The single most useful piece of advice in the published guidance is about modelling habit rather than any tool. Model in the same fashion you would construct the structure: begin with the lowest elevation first and work your way upwards. A model built in construction order answers construction questions without being reorganised first.

Organise the Model Before You Query It

Quantities come out sensibly only if the model is arranged sensibly. There are two structures worth setting up, and they do different jobs.

Structure What it is What it gives you
Building hierarchyA traditional location breakdown structure, with a default hierarchy of project, site, building, level, space.Quantities by where something is. The natural breakdown for a site team.
PhasesA logical grouping of objects, each phase carrying a number, a name and a few other attributes.Quantities by when something happens. The natural breakdown for a programme.

The published guidance ties the two directly to the reports: choose the takeoff by phase or the takeoff by hierarchy depending on which structure you set up. Decide which question you are answering, then build the structure that answers it.

Before You Start

LOD

Agree the level of development first

The guidance opens with establishing the model organisation and the level of development for the model. A model detailed far beyond what the takeoff needs costs time nobody recovers.

ORDER

Model as you build

Lowest elevation first, working upwards, in the sequence the structure goes up. It makes the model readable to people who think in construction sequence.

SOURCE

Decide whose model this is

Contractors often receive models rather than build them. A received model organised for detailing may need categories added before it answers quantity questions.

CONSISTENCY

Quantities are only as good as the inputs

Materials, names and phases have to be applied consistently or the totals split across categories that should be one. This is unglamorous and it is most of the work.

POURS

Cast in situ needs pour management on

If the job has cast-in-place concrete, pour objects are what carry the volumes and formwork areas. That functionality is off by default and has to be enabled.

SHARING

Plan how information leaves the model

Excel from the Object Browser, reports, IFC and Trimble Connect are four different routes to four different audiences. Decide which goes to whom.

The Workflow, Stage by Stage

  1. 1

    Set up the organisation

    Establish the model organisation and the level of development. Define the building hierarchy down through project, site, building, level and space, and set up the phases you will group by.

  2. 2

    Model or receive the structure

    Model the concrete shapes, or insert the design models you were issued. Work from the lowest elevation upwards, repeating for each section, area or elevation.

  3. 3

    Add reinforcement if it is in scope

    Where reinforcement quantities are part of the takeoff, model it, following the reinforcement order of preference rather than hand-modelling bars.

  4. 4

    Open Organizer

    Organizer is the daily tool for managing model information, object property queries and object classification. It has two halves: Object Browser for viewing and reporting on model information from your selection, and categories for classifying objects.

  5. 5

    Build the categories

    Location categories arrange model objects by building location and visualise those locations in the model. Custom categories group by other properties, and filters keep categories updating automatically as the model changes.

  6. 6

    Query and export

    Use Object Browser to view properties in columns you can reorder, sort and group, then export the property values to Microsoft Excel for further processing. The columns export as displayed.

    Create property templates in Organizer to view the properties of selected objects, with grouping, sorting and colour sets for visualisation.

  7. 7

    Run the takeoff reports

    Run the quantity reports from Reports on the Drawings & reports tab, choosing the takeoff by phase or by hierarchy to match how you organised the model.

    A report is a snapshot, Organizer is live

    Organizer syncs with the model and updates as it changes. A report is a file written at the moment you ran it. Use Organizer while the model is moving, and reports when you need a fixed record of what the numbers were on a given day.

  8. 8

    Share with the project

    Attach the model to a Trimble Connect project, download and upload reference models, and export model objects as IFC reference models so that architects, engineers, contractors and owners are working from the same geometry.

What a Contractor Gets That a Detailer Does Not Need

QUANTITIES

Live totals, not a drawing count

Object Browser is a living view of the model that updates with it, which beats counting off drawings and beats a spreadsheet that was true last month.

SEQUENCE

Phases as a programme link

Phases group objects logically and carry a number and a name, which makes them the natural hook between the model and the construction programme.

POUR DATA

Volumes and formwork areas

For cast-in-place work, pour objects report concrete volumes and formwork areas, which are procurement numbers rather than design numbers.

COORDINATION

Everyone else geometry, in one place

Reference models let you check the trades against each other, and clash checking finds the conflicts before they are built rather than after.

SITE LINK

Trimble Connect as the shared floor

Trimble Connect connects constructible data and lets architects, engineers, contractors, owners and operators collaborate on the project.

EXCEL

The format procurement actually uses

Object Browser exports straight to Excel. Most commercial processes end in a spreadsheet, and fighting that is a losing battle.

Being Honest About Scope

Tekla Structures is a detailing and constructible modelling tool. It reports on what is modelled, and it reports it very well. It is not a programme, an estimating package or a procurement system.

The quantity takeoff guidance in Tekla User Assistance is published as contractor material for the United States environment, with named report templates from that environment. The principles carry anywhere, the template names may not, so check what your own environment ships before looking for a report by name.

Where the model needs to drive something beyond reporting, the honest route is out: export to Excel, publish to Trimble Connect, or hand over IFC, and let the system built for that job do it.
