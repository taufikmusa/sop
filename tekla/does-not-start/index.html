Tekla Structures Does Not Start

You click the icon and nothing opens — no window, no error message. What is actually happening behind that silence, how to find the real error in Windows, and the fixes in the order worth trying.

B Short Answer
Short answer

In most cases Tekla Structures is already running in the background. Windows then ignores the new click, so nothing opens.

Please try this first:

  1. Open Windows Task Manager and end every TeklaStructures.exe task.
  2. Restart your computer.
  3. Start Tekla Structures again.

If it still does nothing, open Event Viewer in Windows.

Go to Windows Logs, then Application, and look for the newest line marked Error.

Issue Summary

You start Tekla Structures from the desktop icon or the Start menu, and nothing visible happens. There is no window, no splash screen that stays, and no error message you can send to anyone.

Silence is not the absence of an error. It usually means one of three things: a previous session is still alive in memory, the app started and closed again before it could draw a window, or it is waiting on something it cannot show you — most often the sign in window for the license. Windows records what happened even when Tekla Structures cannot tell you, so the first real job is to read that record.

Before You Start

VERSION

Know your version and service pack

Almost every fix below depends on the exact version and service pack. If you cannot open the app to check, look at the installation folder name under C:\TeklaStructures or the entry in Control Panel > Programs and Features.

RIGHTS

Administrator rights

Reinstalling, installing redistributable packages and editing the registry all need a Windows account with administrator rights. Arrange that with your IT team before you begin, so you are not stopped halfway.

LICENSE

Which license type

An online subscription license and a legacy on-premises license fail in different ways. Know which one you use, because the sign in window steps only apply to the online license.

SYMPTOM

Write down exactly what you see

Nothing at all, a splash screen that vanishes, a frozen window, or a message box — these point to different causes. Note the wording of any message before you click it away.

SCOPE

One model or every model

If Tekla Structures opens and only fails on one model, the app is fine and the model needs attention instead. Test with a brand new empty model to tell the two apart.

CHANGES

What changed recently

A Windows update, a new antivirus policy, a new service pack, or new software installed last week. Tekla User Assistance lists recently installed software as a standard thing to check.

Likely Causes

MOST COMMON

It is already running

A previous session never fully closed and TeklaStructures.exe is still in memory. Your click starts nothing new, because as far as Windows is concerned the app is open. This is why Tekla User Assistance says to end the task in Windows Task Manager before starting again.

LICENSE

The sign in window never appears

With an online license, Tekla Structures has to show a sign in window. When that window fails to appear, startup stops with no visible progress, or you are told no license is available. A wrong system clock, an outdated installation, or a stale license registry value can all do this.

SYSTEM

Missing redistributable packages

Tekla Structures needs specific Microsoft Visual C++ Redistributables and a specific .NET Framework version. When one is missing or damaged, startup fails with System.DllNotFoundException — and sometimes the message flashes past too quickly to read.

CONFLICT

Other software hooking in

Third-party software can hook into Tekla Structures code and stop it running correctly. The usual fingerprint is an APPCRASH event naming TeklaStructures.exe and ntdll.dll in Windows Event Viewer.

SECURITY

Antivirus blocking the executable

Antivirus and endpoint protection can quarantine or block the executable silently, which looks exactly like nothing happening. Checking antivirus settings is on the official troubleshooting checklist.

UPGRADE

A service pack upgrade without signing out

In some older service packs, upgrading while still signed in leaves a cached online license the new build cannot read. You then get a no licenses available message instead of a working start.

MODEL

The model, not the app

If the app opens but freezes on one specific model, the database may be inconsistent. Tekla User Assistance points to the Diagnose & repair commands for that, not to reinstalling.

DRIVERS

Graphics drivers and Windows updates

Outdated graphics drivers and missing Windows updates are both on the official checklist. A driver that cannot create the render window can end the session before anything is drawn.

Resolution

  1. 1

    End the leftover task

    Press Ctrl + Shift + Esc to open Windows Task Manager. Look for TeklaStructures.exe under the Details tab, select it, and end the task. End every instance you find, then start Tekla Structures again.

  2. 2

    Restart the computer

    A full restart is the first general step in the official troubleshooting guide, and it clears locked files and half-released memory that ending a task alone can leave behind. Restart, then try once more before going further.

  3. 3

    Read the real error in Event Viewer

    Open the Event Viewer app in Windows and browse to Windows Logs > Application. Look for an event that has Error in the Level column, around the time you tried to start. Read both the General and Details tabs.

    To keep the evidence, select one or more lines while holding Ctrl or Shift, right-click, and choose Save selected events. That file is what support will ask for.

  4. 4

    Install the latest service pack

    Installing the latest service pack for your version is the third general step in the official guide, and it resolves a large share of startup problems on its own. If no newer service pack exists, uninstall and reinstall the same version.

  5. 5

    Check the redistributables and .NET Framework

    If the error mentions System.DllNotFoundException, check the hardware recommendations for your version to see which Microsoft Visual C++ Redistributables are required. Open Control Panel > Programs and Features and confirm each one is installed.

    On 64-bit Windows each redistributable should appear twice, once as x64 and once as x86. Install anything missing from Microsoft, run each installer and choose Repair where it is offered, then confirm the required .NET Framework version is present.

  6. 6

    Rule out antivirus and recent software

    Check that antivirus or endpoint protection is not blocking the executable, run a malware scan, and review what was installed shortly before the problem started. If Event Viewer shows an APPCRASH event naming ntdll.dll, third-party software hooking into Tekla Structures is the likely culprit.

  7. 7

    If the sign in window never appears

    This branch applies to online subscription licenses only. Start with the system clock: open Settings > Time & Language > Date & time, confirm the time and time zone are correct, and use Sync now.

    Then install the latest service pack and environments into the C:\TeklaStructures folder, using a Windows account with administrator rights. Confirm you are signing in with the same Tekla Online account that holds the license rights, and that the license is not still reserved on another device.

    Registry changes come last, not first

    Tekla User Assistance also documents setting LicenseServerSelected to 2 under HKEY_CURRENT_USER\SOFTWARE\Trimble\Tekla Structures\License, and deleting the HKEY_CURRENT_USER\SOFTWARE\Trimble\Tekla Account key to clear cached account data. Editing the registry can break more than it fixes, so back up the keys first and leave these steps until the time sync and reinstall have both been ruled out. Deleting the account key signs you out, so have your Tekla Online credentials ready.

  8. 8

    If only one model fails

    Create a new empty model. If that opens normally, the installation is healthy and the problem sits in the model database. Use the Diagnose & repair commands on the affected model, and check whether another user can open the same model.

  9. 9

    Collect a crash dump before asking for help

    From version 2019 onwards, dumps are written automatically to %LOCALAPPDATA%\Trimble\Tekla Structures\<version>\Feedback when a crash happens. Paste that path into the Windows Explorer address bar and take the newest file.

    Zip the dump and send it with the saved Event Viewer entries, your exact version and service pack, and a short description of what you see. That package saves a full round of questions.

Version Notes

The general troubleshooting sequence is the same across versions, but two things do differ.

Version What to know
2019 and laterCrash dumps are written automatically to the Feedback folder under %LOCALAPPDATA%, so there is nothing to enable before reproducing the crash.
2020 SP9, 2019i SP10, 2019 SP12Upgrading to these service packs without signing out first leaves a cached online license the new build cannot read, and startup ends with a no licenses available message.
Legacy on-premises licensesStartup can be slow rather than dead, usually a license server name resolution or port delay. Those cases follow the legacy licensing articles, not the sign in window steps above.
Reinstalling is not the first move

It is tempting to reinstall straight away, and it does sometimes work — but it also destroys the evidence in the process. Read Event Viewer first. A five minute look at the Application log often names the exact missing component, and turns a lost afternoon into a five minute fix. Uninstall and reinstall belongs after the latest service pack has been tried, as the official guide sequences it.

Stopping It Happening Again

HABIT

Close properly, not by force

Ending the task every time you finish is what leaves the next session in a strange state. Save and exit through the app, and let it shut down on its own terms.

UPGRADE

Sign out before a service pack

Before installing a new service pack, open a model, clear the stay signed in option under the user icon, and close Tekla Structures. That avoids the cached license problem entirely.

MAINTENANCE

Keep the machine current

Latest service pack, current graphics drivers, installed Windows updates, and a supported operating system. All four appear on the official checklist, and all four are cheaper to maintain than to repair.
