Drawings Not Updating After Model Changes

Tekla Structures 2026 — why a drawing still shows the old geometry, dimensions or marks after the model has been revised, and how to bring it back up to date without losing manual work.

Update Drawings (TUA) How Drawings Are Updated Watch Video

Issue Summary

The customer reports that after revising the model in Tekla Structures 2026, the related drawings still show the old content. In almost every case this is not a defect: Tekla Structures does not update fabrication drawings continuously. It updates them when the model is numbered, and it flags the affected drawings in Document manager so you can update them deliberately.

The three things that most often make a drawing look “stuck” are: the model has not been renumbered, the drawing is frozen, or the change made is one that requires the drawing to be recreated rather than updated. Work through the causes below before escalating.

Before You Start

VERSION

Confirm the version

This guide is written against Tekla Structures 2026. Also confirm which version the drawing was originally created in — that matters, see the version notes below.

ACCESS

Open Document manager

On the Drawings & reports tab, click Document manager. You can also type document manager in Quick Launch, or press Ctrl+L in the model and Ctrl+O when a drawing is open.

PERMISSION

Activate the edit switch

The edit switch in Document manager must be active before you can change the Freeze, Lock or Ready for issuing status of a drawing.

BACKUP

Save the model first

Numbering and updating change drawing content permanently. Save the model before you renumber, especially if the drawings contain a lot of manual dimensioning.

SCOPE

Identify the drawing type

General arrangement (GA) drawings and fabrication drawings behave differently. GA drawings update when you open them; single-part, assembly, cast unit and multidrawings depend on numbering.

EVIDENCE

Read the Changes column

In Document manager, the Changes column describes what changed — for example Parts modified, Quantity increased, or All parts deleted. The Up to date flag shows whether the drawing still needs updating.

Likely Causes

CAUSE 1 · MOST COMMON

The model has not been numbered

Tekla Structures updates drawings each time you number the model. If numbering was never run after the revision, the drawings are simply never told anything changed. Fix: run numbering, then update.

CAUSE 2

The drawing is frozen

Freezing stops the drawing intelligence (associativity). Parts and bolts still follow the model, but dimensions, marks, views and drawing shapes are not updated. This is the classic “the part moved but the dimension didn't” complaint.

CAUSE 3

The change requires recreation

Some drawing settings cannot be applied by updating. Changes such as Coordinate System, Around X/Y/Z, Undeformed, Unfolded, new views, or section settings force Recreate the drawing — and only take effect when you click Modify.

CAUSE 4

Automatic updating is switched off

The advanced option XS_INTELLIGENT_DRAWING_ALLOWED can be set to prevent Tekla Structures from updating drawings automatically when the model changes. XS_INTELLIGENT_DRAWING_ALLOWED_IN_GA does the same for general arrangement drawings only.

CAUSE 5

The drawing came from an older version

Tekla User Assistance warns that updating drawings created in an older version may cause problems after an upgrade. The official recommendation is to finish those drawings in the original version, or recreate them in the new one.

CAUSE 6 · 2026 ONLY

Editing the model with a GA drawing open

In 2026 you can edit the model while a GA drawing is open, and the GA drawing updates live. But numbering is not available in that mode — so fabrication drawings will not be flagged until you close the GA drawing and number the model.

Resolution — Official Update Procedure

  1. 1

    Check the numbering settings

    On the Drawings & reports tab, click Numbering settings > Numbering settings. Select Compare to old for both new parts and modified parts, so existing position numbers are reused wherever the part is unchanged.

    Warning / Troubleshooting

    Position numbers are the identifiers that link a cast unit, assembly, single-part or multidrawing to the model. Many model changes affect numbering, so renumbering is often what actually triggers the drawing update. Getting these settings wrong renumbers parts that did not change and marks far more drawings for update than necessary.

  2. 2

    Number the model

    On the Drawings & reports tab, click Perform numbering and choose either Number series of selected objects or Number modified objects to number only new and modified parts. Tekla Structures updates drawings each time you number the model.

  3. 3

    Check the status flags in Document manager

    Open Document manager and look at the status flag columns — Issue, Ready for issuing, Lock, Freeze, Master and Up to date. Drawings that need updating are flagged. The Changes column tells you what changed in each one.

  4. 4

    Locate the affected parts in the model

    Select the flagged drawings and click the Select objects button in Document manager to highlight the related parts in the model. This confirms the flag corresponds to the revision the customer actually made.

  5. 5

    Review the numbering history log

    Click File > Logs > Numbering history log to see which parts and assemblies were renumbered. Use this to explain to the customer why a given drawing was, or was not, marked for update.

  6. 6

    Update the drawings

    Select the affected drawings in Document manager and click Update. Note that updating a multidrawing automatically updates the drawings linked to it, so you do not need to select those separately.

    Warning / Troubleshooting

    You cannot open a drawing that is not up to date — Tekla Structures requires you to update it first. If a customer says they “cannot open the drawing at all”, this flag is usually the reason, not a corrupted file.

  7. 7

    Create drawings for new parts

    Updating only refreshes drawings that already exist. Any part added to the model during the revision has no drawing yet — create the new drawings separately.

If the Drawing Still Does Not Change

  1. A

    Check the Freeze column, not the Lock column

    In Document manager, activate the edit switch, then click the Freeze column next to the drawing to unfreeze it. For single-part, cast unit and assembly drawings, save the model first and do not save when you reopen the drawing.

  2. B

    Recreate the drawing instead of updating it

    If the change involves view orientation or section settings, open the drawing properties, set Recreate the drawing to Yes, and click Modify. The drawing is recreated only if and when you click Modify. Manual additions in the drawing are not preserved by recreation, so warn the customer first.

  3. C

    Verify the advanced options

    Check whether automatic drawing updating has been disabled in this model or in the company environment. These options are model specific and saved in the options database, so a project handed over from another office can arrive with updating already switched off.

    Category: Drawing Properties

XS_INTELLIGENT_DRAWING_ALLOWED
    Set to FALSE to stop Tekla Structures from automatically
    updating drawings when the model changes.

XS_INTELLIGENT_DRAWING_ALLOWED_IN_GA
    Same effect, but affects general arrangement drawings only.
    Model specific; the setting is saved in the options database.

XS_RECREATE_UNMODIFIED_DRAWINGS
    Referenced together with the options above when controlling
    unwanted recreation of drawings.

XS_ENABLE_MODEL_EDITING_IN_GA          (new in 2026, default TRUE)
    Controls whether the model can be edited while a general
    arrangement drawing is open.

    Confirm the exact wording and default of each option in the Tekla Structures 2026 Advanced options reference before changing anything in a live project.

  4. D

    Ask which version created the drawing

    If the drawing was created in an earlier Tekla Structures version and the model has since been upgraded to 2026, updating it may misbehave. The documented options are to finish the drawing in the original version, or recreate it in 2026.

Freeze vs Lock — Do Not Confuse Them

Status Behaviour / Path
FrozenStops the drawing intelligence (associativity). Model geometry still updates — parts and bolts follow the model — but dimensions, marks, views and drawing shapes are not updated, and marks do not follow moved parts. Toggle via the Freeze column in Document manager with the edit switch active.
LockedMarks the drawing as not available for editing, preventing accidental changes. It does not stop updating: the geometry of a locked drawing still changes when the model changes, and Tekla Structures flags locked drawings for update. The Locked by column shows who locked it. Toggle via the Lock column, or the Lock / Unlock buttons.
NeitherNormal behaviour: flagged in Document manager after numbering, updated with the Update button, fully associative.

Warning / Troubleshooting

Unlocking a drawing will not fix a “dimensions not updating” complaint — locking was never the cause. Check the Freeze column instead. This is the single most common misdiagnosis on this issue.

Drawing Type and Version Notes

Version Behaviour / Path
2026The model can be edited while a GA drawing is open, and changes made to model objects are instantly visible in the drawing — marks, labels, dimensions and templates update automatically. However, numbering is not available in this mode, and the workflow applies to GA drawings only, not fabrication drawings. Controlled by XS_ENABLE_MODEL_EDITING_IN_GA (default TRUE).
2023–2025Same core update model: drawings are updated when the model is numbered, and Document manager flags what needs updating. There is no simultaneous model and GA drawing editing, so the drawing must be closed before the model is edited and numbered.
All versions — GA drawingsGA drawings are updated when you open them if the model has changed, whether or not the model has been numbered. But if the marks use part position numbers, numbering is still required — otherwise old marks show question marks.
Upgraded modelsUpdating drawings created in an older version may cause problems after upgrading. Finish those drawings in the original version, or recreate them in the new version.
