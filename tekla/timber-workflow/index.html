B Short Answer
Short answer

Timber tools are not built into Tekla Structures. They come from Tekla Warehouse.

Install the extension first. Without it there is no timber ribbon tab and no timber objects.

  1. Sign in to Tekla Warehouse and open the Timber tools page.
  2. Download a version compatible with your Tekla Structures.
  3. Import the .tsep through the Extension manager, then restart.
  4. Model beams, columns, plates, walls and slabs from the new tab.
  5. Add screws and connections from the same package.
  6. Number, draw and report as with any other material.

For CLT, the CLT Lamella Visualizer shows the slats and which face is the front.

Issue Summary

The first thing to know about timber in Tekla Structures is the thing nobody tells you before you buy: the timber tools are not in the box. Tekla User Assistance is direct about it. You download the extension package from Tekla Warehouse, on the Timber tools page.

That package contains timber objects, screws and a marker tool, delivered as a ribbon tab. The basic timber objects are timber beams, timber columns, timber plates, timber walls and timber slabs.

Once it is installed, the good news is that timber is not a separate discipline to learn. Each timber object type is modelled similarly to its steel or concrete counterpart, with properties and parameters specific to timber objects. If you can model a steel frame, you can model a timber one.

Before You Start

EXTENSION

Timber is an extension, not a configuration

No licence tier switches it on. The tools arrive by installing a package from Tekla Warehouse, the same way any other .tsep extension is installed.

VERSION

Check compatibility on the Warehouse page

An extension built for one Tekla Structures version is not automatically valid for the next. The version list on the Warehouse item is the authority, not this page and not your memory.

SYSTEM

Know which timber system you build

Glulam portal frames, CLT panels, light timber frame walls and engineered joists are different products with different detailing. What the extension gives you is the object types; the detailing conventions are yours.

FASTENERS

Screws are part of the package

The extension includes screws, which matters because timber connections are fastener-led in a way steel connections are not.

CLT

CLT has a tool of its own

The CLT Lamella Visualizer is a plugin that creates surfaces around parts, set up for CLT walls and floors so the slats are visible and it is clear which is the front and which the back.

OUTPUT

Decide the deliverable early

Timber fabrication data does not have a single dominant standard the way steel has DSTV. Ask your fabricator what their machinery reads before you promise a file.

The Workflow, Stage by Stage

  1. 1

    Install the timber tools

    Sign in to Tekla Warehouse and find the Timber tools page. Download a version listed as compatible with your Tekla Structures version.

    Click Applications & components in the side pane, then Manage extensions > Extension manager. Click Import, browse to the .tsep file, select the versions, and restart Tekla Structures.

  2. 2

    Set the model up

    Create the model and set the grids as for any other job. Nothing about the setup is timber-specific at this stage.

  3. 3

    Model the timber members

    Use the timber ribbon tab the extension adds. Timber beams, timber columns, timber plates, timber walls and timber slabs each behave like their steel or concrete counterpart, with timber-specific properties.

  4. 4

    Handle CLT panels

    For cross laminated timber, launch the CLT Lamella Visualizer by searching for M186 in Applications & components. It creates surfaces around the parts so the slats show and the front and back faces are distinguishable.

    Panel orientation is not cosmetic

    A CLT panel has a strong direction and a face that must end up on the correct side. Making that visible in the model, rather than trusting a note on a drawing, is the point of the visualizer.

  5. 5

    Connect

    Use the screws included in the extension, plus steel connectors modelled as ordinary steel parts where your system uses brackets, hangers and plates.

  6. 6

    Number

    Timber parts number like anything else: set the numbering series on the parts, then run Perform numbering from the Drawings & reports tab. Plan the prefixes so timber, steel connectors and any concrete stay in separate ranges.

  7. 7

    Draw

    Create assembly and single-part drawings for the fabricator and general arrangement drawings for site, using the same drawing layouts and title blocks as the rest of your work.

  8. 8

    Report and hand over

    Run material lists from Reports, and export IFC for coordination. Where your fabricator has machinery that reads a specific format, confirm whether an extension exists for it before assuming one does.

What This Page Cannot Promise

Tekla User Assistance documents the timber objects and the CLT tooling. What it does not publish is a full timber production workflow equivalent to the steel NC file chain or the precast production exports.

That is a real gap rather than an omission on this page. Timber machinery formats vary by manufacturer, and what is available to you depends on which extensions exist for your region and your equipment. Check Tekla Warehouse for your machinery, and ask your local Tekla Support what is current, rather than assuming a format is supported because the material is.

Prove the chain before you commit a job

Model a single representative member, take it all the way through to whatever the fabricator needs, and confirm it arrives usable. Doing that on one member costs an afternoon. Discovering the gap at the end of a project costs considerably more.
