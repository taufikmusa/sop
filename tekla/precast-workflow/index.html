B Short Answer
Short answer

Precast in Tekla Structures runs on one central idea: the cast unit.

A cast unit is the piece that gets cast, moved and erected. Everything downstream reads from it.

  1. Set each concrete part to Precast in the Cast unit section.
  2. Model the panels, then add embeds and reinforcement.
  3. On the Concrete tab, click Cast unit, then Create cast unit.
  4. Run numbering, which behaves differently for precast.
  5. Create cast unit drawings from the numbered model.
  6. Export production data to Unitechnik, ELiPLAN or BVBS.

Precast and cast-in-place parts cannot be mixed inside one cast unit.

Issue Summary

Precast work in Tekla Structures is not a different program hiding behind a switch. It is the same modelling you would do for anything else, organised around one object that everything else hangs off: the cast unit.

A cast unit is the thing that actually gets cast in the factory, loaded onto a truck and lifted into place. Once a cast unit exists and carries the right type, the rest of the chain follows from it. Numbering numbers cast units. Cast unit drawings are drawn per cast unit. Production files are written per cast unit. Get the cast unit right and the workflow works; get it wrong and every stage after it is wrong in the same way.

So the honest answer to “where do I start” is not a menu. It is a decision: what is one piece, and is it precast or cast in place.

Cast Unit or Assembly: Know Which Word You Are Using

Steel people arriving at precast trip over this in the first week. The two words describe the same idea in two materials, and Tekla Structures keeps them apart on purpose.

Term What it groups Drawing it produces
AssemblyA steel main part plus everything welded or bolted to it.Assembly drawing.
Cast unitConcrete parts cast as one monolithic piece, plus their reinforcement and cast-in embeds.Cast unit drawing.

Tekla User Assistance puts the reason for cast units plainly: you need to create cast units when you have several concrete parts which should be cast as one monolithic structure. Cast units can include reinforcement as well as concrete parts.

You can only create cast unit drawings of concrete parts and cast-in embeds, meaning steel parts or assemblies added to a cast unit. A steel bracket that never joins a cast unit will not appear on one.

Before You Start

CONFIGURATION

Check what your licence actually includes

The precast production exports are not in every configuration. Unitechnik and ELiPLAN are described as available in the core installation in the most extensive precast-related configurations, and the Precast Production Export extension lists Diamond, Graphite, Carbon, Partner, Primary, Precast Detailing, Production Planner - Concrete and Full. Confirm yours before you promise a factory a file.

CAST UNIT TYPE

Decide precast or cast in place first

This is a part property, not an afterthought. Some functionality, numbering among it, is based on the cast unit type, so setting it late means redoing work rather than adding to it.

FACTORY FORMAT

Ask the factory what it reads

Unitechnik, ELiPLAN, HMS, BVBS, UXML and PXML are different answers to different machines. The format decides how you must model, so find out before modelling rather than after.

NUMBERING

Plan the series before the first panel

Cast unit prefixes and start numbers belong in the default properties before modelling starts. Concrete part numbering can also inherit from the cast unit, which surprises people who set it up backwards.

COMPONENTS

Precast components need precast cast units

Tekla User Assistance states it directly: precast components can only be applied to precast cast units. They cannot be applied to cast-in-place cast units. A component that refuses to apply is usually telling you the type is wrong.

STANDARDS

Put the setup in the firm folder

Cast unit drawing settings, report templates, embed libraries and export settings are the same on every job. They belong in the firm folder so the next model starts from them.

The Workflow, Stage by Stage

  1. 1

    Set the cast unit type on the concrete parts

    Double-click a concrete part to open the part properties in the property pane and go to the Cast unit section. In the Cast unit list select Precast, then click Modify.

    Cast in place means cast units constructed fully in their final location. Precast means cast units built at another location and transported to their final location. Put this into your default part properties so every new part is born correct.
  2. 2

    Model the concrete

    Model the walls, slabs, beams, columns and stairs as ordinary concrete parts. Nothing precast-specific happens yet, and that is fine. What matters here is that the geometry matches how the piece will actually be produced.

  3. 3

    Add the embeds

    Model cast-in embeds as steel parts or assemblies and add them to the cast unit. For factories reading Unitechnik, the guidance is specific: each embed should be added as a sub-assembly to the main cast unit, with distinct classes, meaningful names or identification codes, and no more than two levels of hierarchy within sub-assemblies.

    Recurring standard embeds are worth building once as custom parts and keeping in the firm folder, rather than remodelling them on every job.

  4. 4

    Reinforce

    On the Rebar tab, use Longitudinal, Crossing, By face or By guidelines to create rebar sets. A rebar set groups bars automatically by geometry, and each set has at least one guideline defining the distribution direction.

    Keep the Direct modification switch active while working with rebar sets. Rebar set property files use the .rst extension.

    Model reinforcement the way the factory makes it

    For automated production, model reinforcement and mesh according to production constraints. Differentiate longitudinal and cross wires by the same class or the same name, and give loose or additional bars their own classes so the factory can filter them. Reinforcement modelled for a drawing and reinforcement modelled for a machine are not always the same thing.

  5. 5

    Create the cast units

    On the Concrete tab, click Cast unit > Create cast unit, select the objects to include, and click the middle mouse button.

    The main part is the one with the largest volume of concrete. To change it, activate the Select objects in assemblies switch, select the part you want, right-click and choose Set as new main part of assembly.

    To check what is actually inside a cast unit, click the down arrow next to the Inquire icon, select Assembly objects, and select a part. Tekla Structures highlights the related objects by type in different colours.

  6. 6

    Number the model

    Run numbering from the Drawings & reports tab. Before you do, check the sort order: the default is XYZ, and you change it in the Numbering Setup dialog using the Sort by and Then by lists.

    Sort order matters more in precast than most people expect, because it decides the order marks are handed out across a building, and that order is what the factory and the site read.

  7. 7

    Create the cast unit drawings

    Cast unit drawings are the dimensional, formwork or reinforcement drawings used in concrete design and construction. They show cast-in embeds, edge chamfers, and hard and soft insulation, and they also show bolts and welds in steel parts.

    Create them the same way as any other fabrication drawing, through the Master drawing catalog or the Create cast unit drawing command, and manage them in Document manager.

  8. 8

    Run the reports

    Cast unit lists, reinforcement schedules and weight reports all come from the same Reports dialog on the Drawings & reports tab, reading straight from the model database. Note that the volume and weight information of a cast unit remains accurate even when there are cuts inside it.

  9. 9

    Export production data

    This is the stage that separates a precast job from an ordinary concrete job, and the format depends on your factory. The table below sets out which is which.

    Numbering has to be up to date before export. For ELiPLAN the documentation is explicit that you need to export all the parts that have been exported before, to ensure proper change management.

  10. 10

    Take the status back from the factory

    The traffic is not one way. For ELiPLAN, the transfer has four parts: exporting the data file from Tekla Structures, importing it into ELiPLAN, exporting a status data file from ELiPLAN, and importing that status file back into Tekla Structures.

    On import, click Create, and Tekla Structures updates the status and schedule data for parts in the model. That status lands in the user-defined attributes of the parts, which means you can filter and colour the model by what the factory has actually cast.

Numbering Behaves Differently in Precast

Two things catch people who come to precast from steel.

The cast unit type drives numbering. It is important to use the correct cast unit type, because some functionalities, numbering among them, are based on it. A piece left as cast in place will not number as a precast element, however it looks on screen.

Concrete parts can inherit their numbering from the cast unit. The advanced option XS_INHERIT_CONCRETE_PART_NUMBERING_SETTINGS_FROM_CAST_UNIT controls this and defaults to TRUE. With it on, the part number prefix for concrete parts includes the cast unit prefix and the start number: with a cast unit prefix of C and start number 100, the concrete part prefix becomes Concrete_C-100. With it off, the prefix is only Concrete.

It affects strip and pad footings, concrete beams and columns, concrete walls and slabs, and concrete polybeams. Decide which behaviour your office wants before the first job, not during the third.

Never mix the two types in one cast unit

Precast and cast-in-place parts cannot be mixed within a cast unit. If a cast unit is refusing to behave, checking the type on every part inside it is the fastest first test.

The Modelling Rules the Export Cares About

A model that draws beautifully can still fail an export, because a production file describes something a drawing never has to: how a machine will build the piece. The Unitechnik guidance is the clearest published statement of what that demands, and much of it applies whichever format you end up using.

CONTOUR

One unified contour per object

Each object should have a unified contour, and there may be openings through the element. Multiple contours cause plotting and shuttering problems, so a panel modelled as two overlapping parts is a problem waiting for the factory to find.

ORIENTATION

Top in form

Use the top-in-form setting within the model to control which way an object faces. The machine needs to know which side lands on the pallet.

EDGES

Line attribute codes

Edge shapes that the shuttering robot has to recognise are modelled using line attribute codes, rather than left for someone to interpret.

EMBEDS

Sub-assemblies with distinct classes

Each embed added as a sub-assembly to the main cast unit, given a distinct class and a meaningful name or identification code, and no deeper than two levels of hierarchy.

PRODUCT TYPE

The UT product type is mandatory

The UT product type must be set for each main part of a cast unit, chosen from options such as Solid wall, Element slab or Sandwich Element. An export that fails with no obvious reason is often a missing product type.

VALIDATE

Check before you send

Before exporting, verify the geometrical objects in the slab blocks, the main attributes for the HEADER and SLABDATE blocks, the contour orientation and line attributes, the mesh production constraints, and the embed plotting results.
