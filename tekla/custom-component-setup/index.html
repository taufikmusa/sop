Setting Up a Custom Component

Model the detail by hand first, then let the wizard turn it into a catalog item you can reuse, share and make adaptive.

B Short Answer
Short answer

Custom components are how you turn a connection you have already modelled into a reusable tool.

Model it once by hand, exactly the way you want it. Then wrap it with the wizard.

  1. Click Applications & components in the side pane.
  2. Click Access advanced features, then Define custom component.
  3. In the Type list, choose connection, detail, seam or part.
  4. Give it a short unique name, then click Next.
  5. Select the objects, then the main part, then the secondary parts.
  6. Click Finish to save it into the catalog.

The order you pick secondary parts in matters. Keep your first version simple.

Issue Summary

A custom component is a connection, detail, seam or part that you model by hand once, and then save so it can be dropped in again anywhere else. It is the answer when no system component in the catalog does what your standard detail needs.

The important thing to understand up front is the order of work. You do not open a blank wizard and build a connection inside it. You model the real thing first, in the model, using ordinary parts, bolts and welds. Only then do you run the wizard, which records what you built and turns it into a catalog item.

That is why most first attempts feel awkward. People expect a form to fill in. What Tekla Structures actually wants is a finished example to copy.

Before You Start

MODEL FIRST

Build the real detail by hand

Create the parts, bolts, welds and cuts in the model exactly as the finished connection should look. The wizard captures what already exists, so anything missing at this point will be missing from the component too.

SCOPE

One situation per component

Tekla User Assistance is direct about this: create simple components for specific situations. They are easier to model, faster to create and simpler to use than one component trying to cover every case.

GEOMETRY

Use the simplest parts you can

Fewer handles means fewer bindings and a component that reacts faster. A rectangular plate is a better building block than a contour plate when both would do the job.

SANDBOX

Consider a separate component model

Building and testing components in their own small model keeps a live project clean while you experiment, and gives you somewhere safe to break things.

NAMING

Short, logical names

Enter short, logical names, and put the explanation in the description field instead. The name is what everyone else in the team has to recognise in the catalog six months from now.

MAIN PART

Know which part is the main part

The wizard asks you to designate a main part and then up to 30 secondary parts. Decide before you start which member the connection belongs to, because that choice drives how the component positions itself.

The Procedure

  1. 1

    Model the detail by hand

    In the model, build the connection exactly as it should be: parts, bolts, welds, cuts and fittings. Work on a real pair of members, for example the beam and the column the detail will normally sit between.

  2. 2

    Open the wizard

    Click the Applications & components button in the side pane to open the Applications & components catalog. Click the Access advanced features button and select Define custom component....

  3. 3

    Set the type and name

    On the Type/Notes tab, select the component type from the Type list: connection, detail, seam or part. Enter a unique name in the Name box, then adjust the Position and Advanced tabs if you need to. Click Next >.

    The Position tab holds the up direction and the position type, such as Middle, Box plane, Collision plane, End plane or Gusset plane. The Advanced tab is where you find the detail type, the definition point options and the Allow multiple instances checkbox.

  4. 4

    Select the objects that belong to the component

    In the model, select the objects you want to include. Area selection works and is usually quicker. Main parts, secondary parts and grids are ignored during this selection, so you are picking the plates, bolts, welds and cuts.

  5. 5

    Pick the main part

    Click Next > and select the main part of the component. For a beam-to-column connection this is normally the column.

  6. 6

    Pick the secondary parts

    Click Next > and select the secondary parts, holding Shift for more than one. A maximum of 30 secondary parts is allowed.

    Selection order is not cosmetic

    Pay attention to the order in which you select secondary parts. That order is stored in the component and decides which member is treated as the first secondary part when the component is used again.

  7. 7

    Finish

    Click Finish. The component is created and appears in the Applications & components catalog, ready to use anywhere in the model. You can add a thumbnail image to it afterwards so it is easy to spot in the catalog.

Making It Adapt Instead of Staying Fixed

A component created this way is a faithful copy of the example you built. Drop it onto members of a different size and the plates will not always follow. That is expected behaviour, not a fault, and the fix is variables.

Open the component in the custom component editor and you can expose distances, profiles and materials as variables. A variable turns a hard number into something the component works out for itself, or something the user sets in the component dialog. This is also where you build the dialog that your team will see when they use the component.

This is the step most people skip on day one, and it is fine to skip it at first. A fixed component that saves you ten minutes is still worth having. Add variables once the component has proved itself.

Test on the odd cases, not the easy one

Before you release a component to the team, try it on the smallest and the largest member you expect it to meet, and on a skewed connection if your work has any. Components almost always behave on the case they were built from.

Sharing Components Across Models and With the Team

Custom components live in the model where they were created. Getting them into the next model is a deliberate step.

To export, click Applications & components in the side pane, select the components you want, right-click the selection and select Publish. Browse to a folder, enter a file name, and the components are saved as a .uel file.

To import, click the Access advanced features button and select Import, browse to the export file, select it, and click Open.

Any data files the component uses have to sit in the model folder or in the CustomComponentDialogFiles subfolder to be included in the exported file.

For a company standard, do not pass .uel files around by hand

If these components are meant to be a company standard, put them in the firm folder instead, so every new model picks them up on its own. Tekla Warehouse is the other route when you want to store and share components across sites.
