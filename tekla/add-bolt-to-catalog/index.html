Adding a New Bolt, Screw or Anchor

It takes two catalogs, not one, and that is why a new bolt so often refuses to appear in the model. The full route from an empty list to a working fastener, including screws and anchors that have no nut at all.

A Question

“How do I create a new bolt, screw and so on? The one I need is not in the list.”

Also asked as

  • I need to add an anchor bolt that is not in the bolt catalog.
  • How do I add a screw that has no nut and no washer?
  • I added a new bolt but I still cannot select it when I place bolts.
  • Where do I add a new bolt size so it shows up in the bolt properties?
  • How do I share my new bolts with the rest of the team and with other models?

B Short Answer
Short answer

There are two catalogs involved, and that is what usually trips people up. A bolt cannot be used until it belongs to a bolt assembly.

  1. Open File, then Catalogs, then Bolt catalog.
  2. Select a similar bolt as your starting point.
  3. Type a unique name, then set Type and Standard.
  4. Click Add, click OK, and save changes to the model folder.
  5. Open File, then Catalogs, then Bolt assembly catalog.
  6. Name the assembly, pick the nut and washer types, then Add and OK.

For a screw or anchor with no nut, leave the nut and washer as they are.

Those need a negative value in the cut length field to force the length.

Issue Summary

Tekla Structures keeps fasteners in two separate catalogs, and understanding the split solves most of the trouble before it starts.

The bolt catalog holds the individual elements: bolts, nuts, washers and studs, each in its own sizes and lengths. The bolt assembly catalog holds the combinations you actually place in a model, each one built from those elements. Tekla User Assistance puts the rule plainly: you cannot use a bolt if it does not belong to a bolt assembly.

That single sentence explains the most common complaint on this subject. Someone adds a bolt, saves, goes to place it, and it is nowhere in the bolt properties. Nothing failed. The bolt exists as an element, and elements are raw material. Only assemblies appear in the list you pick from.

Before You Start

ELEMENTS

Know which elements you need

The Type list offers Bolt, Nut, Washer and Stud. Before you begin, work out which of those your fastener actually needs. An anchor or a self-drilling screw may need only one element and no matching nut at all.

STARTING POINT

Find something similar first

Selecting an existing bolt before you start fills the fields with sensible values, and you edit from there. Building one from a blank row means typing every dimension yourself and finding out later which one you left wrong.

NAMING

Decide the standard name up front

The Standard is what ties an element to an assembly, so a new type of fastener needs its own new standard. Pick the name before you start clicking, because renaming it afterwards means revisiting the assembly too.

LIMITS

Watch the character limits

A bolt name takes up to 40 characters and its standard up to 25. In the bolt assembly catalog the standard takes up to 30 characters, with 25 for the other text boxes. Long descriptive names get cut, so keep them tight.

SCOPE

This saves to one model only

Your additions land in the current model folder, in screwdb.db and assdb.db. Nobody else gets them automatically. Plan how the rest of the team will receive them before you build fifty entries.

DATA

Have the real dimensions ready

Diameter, length, weight, head thickness, thread length. Get them from the manufacturer sheet rather than guessing, because these numbers drive bolt length selection and the weight in your reports.

The Procedure

  1. 1

    Open the bolt catalog

    On the File menu, click Catalogs > Bolt catalog to open the Bolt Catalog dialog. This is the list of individual elements, not the list you pick from when placing bolts.

  2. 2

    Base the new element on an existing one

    Select a bolt from the Bolts list that is close to what you need. Its properties fill the boxes on the right, and you edit from a working starting point rather than an empty one.

  3. 3

    Name it and set the type

    Type a unique name in the box below the Bolts list, up to 40 characters. From the Type list, select the option that defines the bolt element type: bolt, nut, washer or stud.

    Put the size in the name. Six months from now the name is all anyone has to go on.

  4. 4

    Fill in the properties

    Set the Standard and the dimensional values. A new type of fastener needs a new standard name of its own, so it does not inherit behaviour from the family you copied. The full property list is in the table below.

  5. 5

    Add, confirm and save

    Click Add, then OK. In the confirmation dialog, select Save changes to model folder. A new screwdb.db file containing your new parts is created in the current model folder.

    Add creates, Update edits

    These two buttons catch everyone once. Add creates a new entry from what is currently in the boxes. Update writes those values onto the entry that is selected in the list. Edit an existing bolt, type a new name, then click Update instead of Add, and you have quietly renamed a standard bolt that other people in the model are already using. Add first, confirm the new row appears in the list, then adjust it with Update.

  6. 6

    Add the matching nuts and washers

    Repeat steps 2 to 5 for every element the fastener needs, with Type set to nut or washer. Skip this only where the fastener genuinely has none, such as a screw or an expansion anchor.

  7. 7

    Open the bolt assembly catalog

    On the File menu, click Catalogs > Bolt assembly catalog to open the Bolt Assembly Catalog dialog. This is the list that appears as Bolt standard when you place bolts in the model.

  8. 8

    Build the assembly

    Type a unique name in the box below the Bolt assemblies list. Set the Short name, which is what appears in drawings and reports, and the Standard, which is the full name shown in the catalog and in the bolt properties.

    Then set Material, Finish and Grade, and select the washer and nut types that belong to this assembly. Tolerance is there for information only and cannot be reported.

  9. 9

    Add, confirm and save again

    Click Add, then OK, then Save changes to model folder. A new assdb.db file is created in the current model folder. Your fastener is now selectable in the model.

  10. 10

    Test it on a real connection

    Place the new assembly through a plate thickness you actually use, and inquire the bolt. Check that the length Tekla Structures picked is the length you expect. This is the step that catches a wrong calc thick or add. dist before a drawing goes out.

Bolt Catalog Properties

Some of these are pure information, and some of them change how Tekla Structures picks a bolt length. The ones that do the work are marked.

Property What it is
TypeThe type of the bolt element: bolt, nut, washer or stud.
StandardThe name of the bolt element standard, used when you define bolt assemblies. This is the link between the two catalogs.
DiameterThe diameter of the bolt element.
LengthThe length of the bolt element.
WeightThe weight of the bolt element. This is what ends up in your reports, so it is worth getting right.

washer tolThe tolerance between the washer inner diameter and the bolt diameter.

inner diamThe inner diameter of a nut or a washer. For information only.

calc thick and real thick are not the same field twice

It looks like duplication and it is not. real thick is the true thickness and is carried for information. calc thick is the value Tekla Structures actually uses when it works out how long a bolt has to be. Copy a nut, change real thick to match the new one, leave calc thick on the old value, and every bolt through that nut comes out the wrong length — with no error anywhere to tell you.

Screws and Anchors With No Nut

Self-drilling screws, expansion anchors and Hilti-type fixings all share a problem: there is nothing on the far side. No nut, no washer, nothing for Tekla Structures to measure to.

The documented approach is to build them the same way as any other fastener, with two differences at the end.

IN THE CATALOG

Leave the nut and washer alone

Give the screw its own unique standard and its dimensional properties in the bolt catalog. Then, when you build the assembly, since nuts and washers are not used, leave those entries as they are.

IN THE MODEL

Force the length, and clear the checkboxes

Because there is no far side nut or washer, Tekla Structures cannot work out the length by its normal route. Enter a negative value in the cut length field that matches the length in the catalog, and leave the washer and nut checkboxes cleared.

For a stud, the shape is different again. Enter the name, pick the stud icon from the Type list, and set the standard, diameter, length, weight, top thick for the head thickness and top diam for the head diameter. Then create a bolt assembly that uses the stud standard, with every other element set to none.

The negative number is deliberate, not a typo

A negative value in the cut length field is how you tell Tekla Structures to stop calculating and use the length you name. It looks wrong on screen and it is documented behaviour. Make sure the number matches the length you entered in the bolt catalog, or the model and the catalog will disagree about the same screw.

Why a New Bolt Can Show as Not Valid

Adding the bolt is one thing. Getting Tekla Structures to choose it is another, and the logic is worth knowing before you go hunting for a bug that is not there.

Tekla Structures first works out a minimum required length: first washer thickness, plus material thickness, plus second washer thickness, plus any additional washer thickness, plus the first and second nut thicknesses, plus the extra length. It then searches the bolt catalog for the closest match, and checks that candidate against conditions on grip length, thread position and shaft length. If no bolt in the catalog meets the requirements, the model shows that the bolt is not valid.

CAUSE 1

No long enough length exists

You added one length of a new bolt and the connection needs more. The catalog needs the whole range of lengths you intend to use, not just the first one.

CAUSE 2

The thread length blocks it

Grip length and thread position are both checked. A thread len value copied from a different bolt family can rule out every candidate while the lengths themselves look perfectly reasonable.

CAUSE 3

The assembly points elsewhere

The assembly refers to elements by their standard. A typo in the standard name means the assembly is looking for a nut or washer that does not exist under that name.

Getting It Out of One Model

Everything so far lives in one model folder. There are three documented ways to move it, and they suit different situations.

A FEW ENTRIES

Export and import selected items

Select the entries with Shift and Ctrl, right-click, and choose Export. Bolts go to a .bolts file and assemblies to a .bass file. Importing is the same route with Import. Exported assemblies bring their bolts, studs, screws, nuts and washers along with them.

THE WHOLE CATALOG

Export the catalog as a list file

Run the Export Bolt Catalog command from Quick Launch and the catalog is written as screwdb.lis in the model folder. To bring it in elsewhere, copy that file to the other model folder and run Import Bolt Catalog.

EVERY NEW MODEL

Copy the file to the firm folder

Copy screwdb.db and assdb.db to the firm folder or to a model template, and new projects pick them up from there. This is the option to choose when the fastener is a company standard rather than a one-off.

Importing does not overwrite what is already there

When you import a bolt catalog, Tekla Structures does not replace entries that have the same names as the entries in the import file. So a corrected version of a bolt you already have will be silently ignored, and you will spend an afternoon wondering why the fix did not arrive. Importing bolt assemblies is different: where names clash, a Review import items dialog appears and you choose Leave or Replace for each one. When you are correcting an existing entry rather than adding a new one, edit it in the target model or delete it first.
