Part Marks for Beams and Columns

A part mark is a prefix plus a start number, assigned to the part and produced by numbering. Here is where to set it, and how to read it on screen.

A Question

“How do I set the part mark for a beam, a column or other material, so each type gets its own numbers?”

  • How do I see the part mark on screen in the model, not only in the drawing?
  • What is the difference between the part position number and the assembly position number?
  • Two identical beams got different marks. Why?

B Short Answer
Short answer

A part mark comes from a numbering series: a prefix plus a start number.

You set it on the part itself, then run numbering. The mark only exists after numbering.

  1. Double-click the part to open its properties in the property pane.
  2. Under Numbering series, enter a part prefix and a start number.
  3. Set the assembly prefix and start number in the same place.
  4. Click Modify.
  5. On the Drawings & reports tab, click Perform numbering, then Number modified objects.

To see marks on screen, add a part label on the Advanced tab of the view Display dialog.

Issue Summary

A part mark in Tekla Structures is not typed in. It is calculated. What you set on the part is the numbering series it belongs to, and a numbering series is made of two things: a prefix and a start number.

Define a series with the prefix P and start number 1001, and Tekla Structures numbers that series P1001, P1002, P1003, and so on. The prefix is optional, so minor parts can be numbered without one.

The rule that decides which parts share a mark is worth memorising: all identical objects within tolerance and in the same numbering series are given the same position number. Two beams that are geometrically the same but sit in different series will never share a mark, and that is exactly how you keep beams, columns and braces in separate number ranges.

Two Marks Per Part, Not One

This trips up almost everyone in the first week. A single steel member carries two position numbers, and they are set in two different boxes.

Number What it counts Typical use
Part position numberThe single piece of steel on its own, before anything is welded to it.Single-part drawings, cutting lists, the shop floor cutting the raw member.
Assembly position numberThe whole welded assembly: main part plus everything welded to it.Assembly drawings, shipping lists, erection marks on site.

So a column with two welded-on end plates has one assembly mark and three part marks. When someone says “the mark on the beam”, ask which of the two they mean, because a prefix set in the wrong box produces marks that look right and count wrong.

Before You Start

PLANNING

Decide the whole scheme first

Tekla User Assistance is blunt about it: plan the numbering prefixes and start numbers for the entire project before you start modelling. Careful planning prevents numbering conflicts, and conflicts found later are expensive.

DEFAULTS

Put the series in the default properties

To save time, include the numbering series in the default part properties for each type of part before you start modelling. Then every new beam is born in the right series and nobody has to remember.

RANGES

Leave room between ranges

If beams start at 1 and columns start at 100, a job with 120 beam marks will run straight into the column range. Overlapping numbers stop those objects being numbered at all.

CLASSIFYING

Do not use marks to sort parts

Numbering is not just another way of classifying parts. To classify, use Organizer, user-defined attributes or colours. A prefix scheme built to double as a filing system gets messy fast.

CONCRETE

Concrete follows the cast unit

When XS_INHERIT_CONCRETE_PART_NUMBERING_SETTINGS_FROM_CAST_UNIT is enabled, which is the default, concrete parts are numbered according to the cast unit numbering settings rather than their own.

TIMING

Number on a routine

It is a good idea to have some kind of routine in numbering. Number the model when you start your working day, or when you finish for the day, so marks and drawings never drift far apart.

Setting the Part Mark on a Beam or Column

  1. 1

    Select the part and open its properties

    Double-click the part in the model. The part properties open in the property pane.

  2. 2

    Fill in the part numbering series

    Under Numbering series, define a part prefix and a start number. This is the mark for the single piece: the raw beam or column on its own.

    A common steel convention is B for beams, C for columns, BR for braces and P for plates, each with its own start number.

  3. 3

    Fill in the assembly numbering series

    In the same section, set the assembly prefix and start number. This is the mark the fabricator and the erector will use.

  4. 4

    Click Modify

    The part now belongs to the series. Nothing visible changes yet, because the mark itself does not exist until numbering runs.

  5. 5

    Run numbering

    On the Drawings & reports tab, click Perform numbering > Number modified objects. Check the proposed numbers in the Numbering preview dialog, then click Assign numbers.

    Change series first, number second

    Assigning a new series to parts that already carry marks will change those marks on the next numbering run. Do this deliberately, and check the numbering preview before you accept it, especially once drawings exist.

Setting the Series on the Assembly Instead

There are two ways in, and which one you use depends on what your selection switches are set to.

Through the main part: activate the Select objects in assemblies switch, double-click the assembly main part to open the part properties in the property pane, and under Numbering series enter an assembly prefix and start number. Click Modify.

Through the assembly: activate the Select assemblies switch, double-click the assembly to open the assembly properties in the property pane, define a prefix and start number in the assembly numbering boxes, and click Modify.

Check which part is the main part

In the first method the assembly numbering rides on the main part, so identify the main part before you edit it. Editing a secondary part and expecting the assembly mark to change is a wasted afternoon.

Seeing the Mark in the Model View

Marks are visible in drawings and reports by default. To read them on screen while modelling, switch on part labels for the view.

  1. 1

    Open the view properties

    Double-click the view background to open the View properties dialog.

  2. 2

    Open the Display dialog

    Click Display... to open the Display dialog, then go to the Advanced tab.

  3. 3

    Add the properties you want to see

    In the Properties list, select a property such as the position number, and click Add > to move it into the part label list. The checkbox switches itself on as soon as something is in the list.

    To show a user-defined attribute, select User-defined attribute from the list, click Add >, and type the attribute name exactly as it appears in the objects.inp file.

  4. 4

    Choose how much to label

    In the Show for list, choose All, Selected, Main part for selected or Main part for all. On a large model, Selected keeps the view readable.

  5. 5

    Apply

    Click Modify. The labels appear next to the parts. The label colour is controlled by the advanced option XS_VIEW_PART_LABEL_COLOR.

When the Marks Are Not What You Expected

Two parts that look the same to you but get different marks are almost always being separated by something in the numbering settings, not by the series. Bolt holes, part name, beam orientation, assembly phase, welds and surface treatment can each be set to affect numbering.

Two parts that share a mark when they should not are usually inside the numbering tolerance, or the property that distinguishes them has been switched off in the numbering settings.

If Tekla Structures warns about overlapping position numbers, take it seriously. Objects with overlapping numbers will not be numbered at all, so a warning ignored today becomes an unnumbered part in a report next week.
