Showing Only Certain Views for Checking

Named views, view filters, selection filters, hide, and view depth are five different answers to one request. Here is which to reach for.

A Question

“How do I look at only certain views or certain parts when I check the model, instead of the whole thing at once?”

Also asked as

  • How do I create and save a view for one gridline or one floor?
  • How do I show only the steel and hide everything else in a view?
  • Where is the list of views in the model?
  • How do I stop selecting the reference model every time I click in the view?
  • My saved views disappeared after I closed the model.

Generic form of a real customer question — names, company and project details removed. Tekla Structures 2026.

B Short Answer
Short answer

Three separate tools do this, and picking the right one saves a lot of clicking.

Named views control where you look, and view filters control what is drawn.

Selection filters control what you can pick. Use all three together.

  1. On the View tab, click New view, then Basic view.
  2. Choose the plane, enter the level, then click Create.
  3. Name the view so it survives the session.
  4. Double-click the view background to open View properties.
  5. Choose a filter in the Visible object group list, then click Modify.
  6. Pick a selection filter from the list on the Selecting toolbar.

Only nine views can be open at once. Manage the rest in the side pane.

Issue Summary

“Show me only what I want to check” sounds like one request. In Tekla Structures it is answered by several different mechanisms, and using the wrong one is why people end up scrolling through a whole model to inspect one connection.

Sorting out which does what takes a few minutes and pays for itself every day afterwards. The five below cover almost every case.

Mechanism What it controls Lasts
Named viewsWhere you are looking from, and at what.Permanent, once the view is named and the model is exited properly.
View filterWhich objects are drawn in a view at all.Stays with the view until you change it.
Selection filterWhich objects you can pick, regardless of what is drawn.Stays until you switch the filter back.
Hide and Show only selectedA quick, throwaway change to what is visible.Until the next redraw.
Work area and view depthThe slice of the model a view shows at all.Stays with the view.

Creating the Views You Need

  1. 1

    Pick the kind of view

    On the View tab, click New view. The options include Basic view, Using two points, Using three points, On work plane, Along grid lines, On selected building storeys, On plane, 3D view of part, Default part views and several more.

    For checking work, Along grid lines and On selected building storeys are usually the two that pay off fastest, because they create a set of views matching how the job is actually organised.

  2. 2

    Create a basic view

    Click New view > Basic view, select a view plane from the Plane list, enter the view level in the Coordinate box to set the distance from the global origin, and click Create.

  3. 3

    Name it straight away

    A view with a default name in parentheses is a temporary view. Rename it to make it permanent.

    Views are only written out when you exit

    Tekla Structures only saves the named views when you exit the model. Name the views you want to keep before closing, and close the model properly rather than ending the process, or the work is gone.

  4. 4

    Set the view depth

    Double-click the view background to open View properties. The view depth is the thickness of the displayed slice of model, and you can define the depth separately upwards and downwards from the view plane.

    A shallow depth on a plan view is the difference between checking one floor and squinting at the whole building.

  5. 5

    Keep them organised

    Click the model views button in the side pane to open the Model views window, which lists every view in the model. Right-click a view for Open view, Close view, Rename, Delete or Bring to front.

    Create folders and drag views into them, and use the search box when the list grows. There is a nine view limit on how many can be open at the same time, so the side pane is how you live with more than nine.

Showing Only Certain Objects in a View

A view filter decides what is drawn. Everything else is simply not there, which makes a crowded model readable.

  1. 1

    Open the view properties

    Double-click the view to open the View properties dialog.

  2. 2

    Choose a filter

    Select a filter from the Visible object group list and click Modify. Tekla Structures comes with standard filters, and your environment may add more.

  3. 3

    Build your own if the standard ones do not fit

    In View properties, click Object group to open the Object group - View filter dialog, which shows the currently active filter. Click New filter to start from scratch, then Add row to add a filter rule.

    Save the filters your team uses repeatedly and put them in the firm folder, so everyone checks the model through the same lens.

  4. 4

    Switch it off again

    Return to View properties, select the standard filter, and click Modify. A filter left on and forgotten is a common reason for “my parts have disappeared”.

Controlling What You Can Pick

A view filter changes what you see. A selection filter changes what you can grab, which is the more useful one when you are picking objects out of a busy area.

The filter list sits on the Selecting toolbar, normally at the bottom of the main window. Choose a filter there, then click in the model, and only objects matching that filter are selected. The rest are not affected even if you drag a box across them.

To clear it, select the standard filter from the same list. Remember that objects have to be visible in the view to be selectable, so a view filter and a selection filter can fight each other.

The reference model needs its own switches

Clicking into an IFC or DWG reference is controlled by the selection switches, not by filters. Activate Select reference models together with Select components for the whole model, or with Select objects in components to reach a single object inside it.

The Quick, Temporary Version

Sometimes you do not want a saved view or a filter. You want two beams out of the way for the next thirty seconds.

Select the parts, right-click and select Hide. The hidden parts are shown as reference lines. Hold Shift while giving the command to hide them completely instead.

The opposite is Show only selected. Select the parts you want to keep, right-click and choose it, and everything else appears almost transparent. Hold Shift to hide the rest entirely, or Ctrl to show them as reference lines.

To put everything back, click the refresh icon on the View tab, or right-click in the view and select Redraw view. That also restores the display settings after commands such as Show assembly or Show component content.

Temporary means temporary

Anything hidden this way comes back at the next redraw. Do not use it to prepare something you intend to look at again tomorrow, and do not rely on it to prove a part is not there.

A Setup That Works for Checking

A pattern worth stealing: keep a 3D view for orientation, a plan view for the floor you are working on, and an elevation for verification. Tekla User Assistance suggests exactly this combination, and Ctrl+P switches between a 3D view and a plane view.

Add a view filter that hides the trades you are not responsible for, a selection filter matching what you are picking, and a shallow view depth on the plan. At that point the model shows the thing you are checking and very little else, which is the whole point of the exercise.
