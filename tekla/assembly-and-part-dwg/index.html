B Short Answer
Short answer

This is two jobs. Create the drawings in the model, then export them as DWG.

Number the model first. A part with no mark cannot get a drawing.

  1. Activate the Select parts switch and select the parts.
  2. In Quick Launch, run Create assembly drawing.
  3. Repeat with Create single-part drawing for the part drawings.
  4. On the Drawings & reports tab, open Document manager.
  5. Select the drawings, then click Export.
  6. Choose DWG, set the folder, and export.

Existing drawings are never duplicated. One with the same type and mark is skipped.

Issue Summary

Getting DWG files to a fabricator is two separate operations that people often merge into one question. First Tekla Structures creates drawings inside the model, as native drawings held in the model database. Then those drawings are exported to DWG files on disk.

Nothing about the export decides what is on the sheet. If the assembly drawing is missing views, dimensions or a title block, that is a drawing creation problem, and exporting it again in a different format will not help.

The other thing worth knowing before you begin: numbering comes first. Drawing creation depends on part marks, and Tekla Structures prompts you to number the model if you have not.

Before You Start

NUMBERING

Number the model

Marks identify the drawings. Run Perform numbering before you create anything, and expect a prompt if you forget. Creating drawings on an unnumbered model produces work you will throw away.

PROPERTIES

Load the right drawing properties

Load predefined drawing properties that match the drawing type you are creating, set up the view creation settings, add the views you need, and save the drawing properties before you run the command.

LAYOUT

Have the sheet sorted first

Title block, sheet sizes and table sets belong in place before you create hundreds of drawings. Fixing the layout afterwards means recreating or updating every sheet.

TYPE

Know which drawing you actually need

A single-part drawing shows one piece of steel on its own. An assembly drawing shows the welded assembly. Fabricators normally want both, and they are created by two separate commands.

SELECTION

Set the selection switch

Activate only the Select parts switch on the Selecting toolbar. A stray selection switch is the usual reason a creation command produces fewer drawings than expected.

BATCH SIZE

Start with a handful

Create three or four drawings, check them, then run the whole model. Reviewing a bad template across four hundred sheets is a bad afternoon.

Part One: Creating the Drawings

There is a fast route for a handful of parts, and a controlled route for a whole job.

  1. 1

    Select the parts

    Activate only the Select parts switch on the Selecting toolbar, then select the parts in the model.

  2. 2

    Run the command from Quick Launch

    Type into the Quick Launch box and run one of Create single-part drawing, Create assembly drawing or Create cast unit drawing.

    To open a drawing automatically once it is created, hold down Ctrl+Shift while you create it. Useful when you are checking a template, not when you are creating four hundred sheets.

  3. 3

    Let it skip what already exists

    If you already have a drawing with the same type and mark, Tekla Structures will not create a new one. Running the command again over the whole model is therefore safe: it fills the gaps rather than duplicating.

  4. 4

    Find the results in Document manager

    The created drawings are listed in the Document manager. This is where you will select, open, revise, print and export them from now on.

  5. 5

    For a whole job, use the Master drawing catalog

    On the Drawings & reports tab, click Master drawing catalog. A master drawing is a Tekla Structures drawing, or a set of drawing properties, that is used for creating new drawings that look the same as the master drawing.

    The catalog gathers all drawing creation commands in one place and supports cloning templates, saved settings, rule sets and existing wizard files. It is the difference between a consistent set of drawings and four hundred sheets that each look slightly different.

Single-Part Views Inside Assembly Drawings

Many fabricators would rather have one assembly sheet showing the individual pieces than two separate stacks of paper. Tekla Structures supports that directly.

You can include in assembly drawings single-part drawing views of the individual parts that make up the assembly, either by using existing single-part drawings from Document manager or by creating new single-part drawing views inside the assembly drawing.

Decide this before you generate the set. Switching approach halfway leaves you with two conventions in one issue, and a fabricator asking which sheet is the current one.

Part Two: Exporting to DWG

Three routes lead to the same dialog. Pick whichever fits what you are already doing.

Starting point How to get there
From the File menuOn the File menu, click Export > Drawings, and select the drawings from the displayed Document manager list.
From Document managerClick Drawings & reports > Document manager, select the drawings, right-click and select Export, or click the Export button at the bottom.
From an open drawingOn the File menu, click Export drawings.
  1. 1

    Set the file type and version

    In the File type list, select DWG, DXF or DGN (V8). For DWG and DXF, select the version to use in the export. Several AutoCAD and DXF format versions are available, and 2010 is the default.

    Ask the receiving office which version their software reads comfortably. Exporting to the newest format available helps nobody if the fabricator opens it in an older application.

  2. 2

    Set the output folder

    The default location for the exported files is the current model folder. Point it somewhere deliberate instead, so an issue to the fabricator is a folder you can zip and send.

  3. 3

    Handle the file names

    On the export file settings, enter the export file name. If you are exporting several drawings, leave the file name box empty, and each drawing is named from its own mark rather than overwriting one file.

    Prefixes and suffixes are available on the Options tab. There are also drawing-type-specific advanced options such as XS_DRAWING_PLOT_FILE_NAME_A for assembly drawings and XS_DRAWING_PLOT_FILE_NAME_C for other types, for offices that need a strict naming convention.

  4. 4

    Set the layer rules

    On the Layer rules tab for DWG and DXF, or the Level rules tab for DGN, define explicitly the layers or levels where different model and drawing objects are exported to.

    A rule can specify the objects, presentation filtering, object filtering, the target layer, colour, line style, line weight, and whether the objects go to paper space or coordinate space. This is what turns a Tekla drawing into a DWG that behaves properly in the fabricator drafting software.

  5. 5

    Export and check one file

    Run the export, then open one exported file in a DWG viewer before sending the batch. Check the title block, the logo, the dimensions and the layers.

The Traps Worth Knowing

The logo can arrive as an empty frame

When a drawing is exported to DWG, Tekla Structures copies the images into the same folder as the DWG file. If the image is not there, only an empty frame is shown. Keep the logo file with the exported drawings, or set the image path with the advanced option DXK_SYMBOLPATH so it is found reliably.

Missing drawings usually means missing marks

If a creation command produced fewer drawings than there are parts, check numbering first, then the selection switch, then whether those parts already have a drawing of that type. Those three explain almost every case.

Export does not fix content

A dimension missing in the DWG is a dimension missing in the Tekla drawing. Fix it in the drawing, or in the drawing properties that generated it, and export again.
