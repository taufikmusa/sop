Purlins, rails, stud walls and modular framing. The work is component-led, the components are manufacturer-specific, and your region decides which ones you get.

B Short Answer
Short answer

Cold-formed and light gauge work is component-led rather than command-led.

The value sits in manufacturer systems and framing components, not in new tools.

  1. Confirm which manufacturer system your work actually uses.
  2. Check whether that system is built in or on Tekla Warehouse.
  3. Install any extension through the Extension manager, then restart.
  4. Model the walls, roofs, trusses and floors with those components.
  5. Use the manufacturer file transfer to validate before ordering.
  6. Number, draw and export as for any steel job.

Most cold rolled systems are already in the software, and some come from Tekla Warehouse.

Issue Summary

“Metal” covers several different businesses, so it is worth being precise about which one this page is for. It is written for cold-formed and light gauge steel: purlins and side rails, metal stud framing, modular cold-rolled walls, roofs, trusses and floors.

If your work is hot-rolled structural steel, the steel workflow page is the one you want instead. If it is plate work — cones, hoppers, rolled plates, anything that has to be unfolded into a flat pattern before it is cut — that is the sheet metal and plate work page, which is a different discipline from the manufacturer systems described here.

The shape of the cold-formed workflow is different from hot-rolled steel in one important way. You are not usually inventing connections. You are using a manufacturer system, with its own sections, its own accessories and its own rules, and Tekla Structures has tools built with those manufacturers to match.

What Actually Exists

MANUFACTURERS

Systems built with the makers

Tekla has created tools in conjunction with major UK cold-rolled steel manufacturers so that models can use their systems, designed to work with each specific manufacturer rules. Named manufacturers include Albion, Ayrshire Metal, BW Industries, Composite Metal Flooring, Duggan Steel Group, Kingspan, Metsec, Thomas Panels and Profiles, Reid Steel, Steadmans Steel Sections and Ultrazed Steel.

WHERE

Mostly built in, sometimes not

The documentation puts it plainly: currently most cold rolled steel systems are available within the software, however some systems are available via Tekla Warehouse. Check before assuming either way.

COMPONENTS

Intelligent joints and macros

Intelligent joints and macros allow rapid modelling and updating of cold rolled accessories. This is the difference between placing a system and drawing every cleat by hand.

ORDERING

File transfer to the manufacturer

Most manufacturers provide file transfer functionality to validate items before ordering, and it produces the necessary files required to place your order. That is your production output on this kind of job.

FRAMING

General framing tools

An extension provides general framing tools for creating modular cold-rolled steel walls, roofs, trusses and floors, for work that is not tied to one manufacturer system.

STUDS

Metal stud frames

A bundle of three custom components creates metal stud frame walls with or without openings using light gauge profiles: track runners top and bottom, vertical struts spaced per the user input, and lintels and sills at openings where appropriate.

Before You Start

REGION

These tools are regional

The cold rolled manufacturer list is a UK list. Metal Stud Frames is documented for the United States (Imperial) and United States (Metric) environments, available in the US environment model templates. Your environment decides what you see.

SYSTEM

Pick the system before the model

Each manufacturer system carries its own sections and its own rules. Modelling generically and swapping to a system later means redoing the connections you already placed.

UPDATES

Use the current release

The guidance is explicit: always use the latest software release, because revisions made by manufacturers will generally not be back dated to older versions. A system that behaved one way two versions ago may have been corrected since.

CATALOGS

Check the sections exist

Confirm the profiles you buy are in the catalog, in the sizes and gauges you use. Cold-formed sections are more numerous and more manufacturer-specific than hot-rolled ones.

ANALYSIS

Know the design boundary

Cold-rolled members can be modelled and analysed in Tekla Structural Designer, but cannot be designed there. The design normally stays with the manufacturer, and the model carries the result.

OUTPUT

Ask what the shop needs

A manufacturer order file, NC data, drawings and IFC are different deliverables. On a system job the order file is often the one that matters most.

The Workflow, Stage by Stage

  1. 1

    Identify the system

    Establish which manufacturer system the job uses, and whether the tools for it are already in your installation or need downloading from Tekla Warehouse.

  2. 2

    Install anything missing

    For a Warehouse item, click Applications & components in the side pane, then Manage extensions > Extension manager. Click Import, browse to the .tsep file, select the versions, and restart Tekla Structures.

  3. 3

    Model the primary structure

    Where there is a hot-rolled frame carrying the cold-formed work, model it first. The purlins, rails and stud walls attach to it, and they need something to attach to.

  4. 4

    Place the system

    Use the manufacturer components and the framing tools to create the walls, roofs, trusses and floors. Let the intelligent joints and macros handle the accessories rather than modelling cleats individually.

  5. 5

    Build the stud walls

    Where the work is metal stud framing, use the metal stud frame components, which create the walls with or without openings and place the track runners, struts, lintels and sills.

  6. 6

    Validate with the manufacturer

    Use the file transfer functionality the manufacturer provides to validate the items before ordering. Doing this before drawings are issued catches a wrong section while it is still cheap to change.

  7. 7

    Number, draw and report

    From here the job behaves like any steel job: set the numbering series, number the model, create the drawings, and run the material lists.

    Plan the numbering ranges across systems

    Cold-formed accessories multiply quickly, and a single wall can contain hundreds of near-identical pieces. Decide the numbering series and what counts as the same part before modelling, or the mark list becomes unusable.

  8. 8

    Produce the order and coordination files

    Generate the manufacturer order files for the system work, NC data for any hot-rolled steel, and IFC for coordination with the other trades.

Being Honest About the Gaps

This is the workflow in this set with the most variation between offices, because so much of it depends on which manufacturer you buy from and which region you work in.

Tekla User Assistance documents that the manufacturer tools exist and names the manufacturers. It does not publish a single step-by-step cold-formed workflow article in the product guides, and the per-manufacturer detail lives with each system rather than in one place.

The two documented facts worth carrying away are these: most cold rolled systems are already in the software, and the ones that are not are on Tekla Warehouse. If a system you need appears in neither, your local Tekla Support is the place to ask what is planned.
