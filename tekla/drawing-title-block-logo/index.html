Title Block and Logo for A1 and A3

Template Editor draws the block, the layout editor decides where it sits on each sheet size, and one advanced option decides whether your logo ever prints.

B Short Answer
Short answer

Two tools are involved, and that is what makes this feel harder than it is.

Template Editor draws the title block. The drawing layout editor places it on each sheet size.

  1. In Template Editor, open the title block and click Insert, then Picture.
  2. Select the logo file, then pick two corners for it.
  3. Save the template into your firm folder.
  4. On the File menu, click Editors, then Drawing layout editor.
  5. Create a layout and add the drawing sizes A1 and A3.
  6. Click Add tables, place the title block, then click Save as.

Set DXK_SYMBOLPATH to the logo folder, or the image shows only in the editor.

Issue Summary

A company title block is two jobs wearing one name. The graphics, the boxes, the text and the logo are drawn in Template Editor. Deciding which sheet sizes exist and where that title block sits on each of them happens in the drawing layout editor.

People usually get halfway. The title block gets built and looks perfect in Template Editor, then it either never appears on the sheet, or appears in the wrong place on A3 because only A1 was set up.

The vocabulary below is worth five minutes. Once these four words are clear, the rest of this page is mechanical.

The Four Words That Matter

Term What it means
TableA Template Editor template placed in a drawing, containing information about model objects. Your title block is a table. So is a revision table, a bill of materials or a key plan.
Table setA group of tables or templates included in a drawing of a particular type and size. This is the collection that appears together on one sheet.
Drawing sizeA named sheet size such as A1 or A3, with its width and height. Different sizes can carry different table sets.
Drawing layoutThe thing that ties it all together. A layout defines which tables to include in a drawing and where the tables are located, along with view margins, spacing, frames and foldmarks.

The practical upshot: using different layouts you can set assembly drawings to use A1 and A2 sheets, and single-part drawings to use A3 and A4 sheets. That is exactly the arrangement most steel offices want.

Part One: Build the Title Block in Template Editor

  1. 1

    Open Template Editor

    On the File menu, click Editors > Template editor. Open the title block template you want to change, or start from an existing one rather than a blank page.

  2. 2

    Set the picture folder before you insert anything

    In Template Editor, click Options > Preferences and go to the File Locations tab. On the Symbols, pictures row, add the folder holding your logo, separated from the existing entries by a semicolon.

    Tekla Structures looks for images in the model folder first, then in the symbols folder in the current environment. Anywhere else has to be registered here.

  3. 3

    Insert the logo

    Click Insert > Picture. The Select Picture File dialog opens. Select the file and click OK.

    Then define the insertion point: either click twice to define the opposing corners, or drag and release. The logo appears in the template and in the Content Browser as a Picture.

  4. 4

    Check the file format

    Supported formats are BMP, GIF, GRD, JPG, PPM, PGM, PNG, RLE, TIFF and XKRL. A PNG at a sensible size is the safe choice.

    Keep the image small

    Very large images update very slowly. Scale the logo down to roughly the size it will print at before you insert it, rather than dropping in a print-resolution file and shrinking it on screen.

  5. 5

    Add the fields around it

    Fill in the rest of the title block with the value fields your office needs: project name, drawing number, scale, revision, checked by. These come from model and drawing attributes, so they fill themselves in on every sheet.

  6. 6

    Save it where everyone gets it

    Save the template, then place it in your firm folder so every model uses the same one. A title block that lives in a single model folder is a title block you will rebuild next year.

The Logo Shows in the Editor but Not in the Drawing

This is the single most common complaint on this subject, and it is not a fault. Template Editor and Tekla Structures each look for the image file in their own way, and both have to be told where it is.

You have already set the folder in Template Editor preferences. Now set the same folder for Tekla Structures using the advanced option DXK_SYMBOLPATH, by adding a line to user.ini:

set DXK_SYMBOLPATH=%DXK_SYMBOLPATH%;C:\TeklaStructures\FIRM\Bitmaps

Replace the path with your own folder, and keep the semicolon so the existing paths survive. Close Tekla Structures completely and reopen it for the change to take effect.

The same rule bites again on export

When a drawing is exported to DWG, Tekla Structures copies the images into the same folder as the DWG file. If the image is not there, only an empty frame is shown. Keep the image next to the exported files when you send drawings out.

Part Two: Set Up A1 and A3 in the Layout Editor

  1. 1

    Open the drawing layout editor

    On the File menu, select Editors > Drawing layout editor. You can also reach it from the Drawings & reports tab under Drawing properties > Drawing layout editor, or by typing its name into the Quick Launch box.

  2. 2

    Create the layout

    Click Create layout, give it a name of up to 63 characters, and select the drawing size to start from. Click Create.

  3. 3

    Add the sheet sizes you need

    Click the edit button next to the Drawing size list, then click the plus button under the existing sizes. Select a predefined size or type a name of your own, and double-click the Width and Height boxes to enter values. Click OK.

    Add A1 and A3 here as separate sizes. Each one can then carry its own arrangement of tables.

  4. 4

    Place the title block

    Click Add tables, select your title block template, and click the point in the layout where it belongs. Add the revision table, bill of materials or key plan the same way.

    To remove a table, right-click it and select Delete, or select it and press the Delete key.

  5. 5

    Adjust the frame

    In the drawing size settings, set the frame distances from the left, right, bottom and top edges, and pick the frame colour. This is also where foldmarks are handled.

  6. 6

    Choose which drawing types use this layout

    Select the applicable drawing types in the layout editor side pane. This is how assembly drawings end up on A1 while single-part drawings end up on A3.

  7. 7

    Save

    Click Save as on the ribbon, enter a name in the Save layout with a name box, and select the drawing sizes it applies to. There is a Synchronize listed sizes with paper sizes for printing option worth selecting so printing matches the sheet.

    Click Save.

Different Tables on A1 and on A3

An A1 assembly sheet and an A3 single-part sheet rarely want the same furniture. A full bill of materials that fits comfortably on A1 crowds an A3 sheet badly.

Because a table set belongs to a drawing size within a layout, you can give each size its own set. Use the same table layout with different drawing sizes when they genuinely match, and give a size its own table layout when it does not.

A workable pattern for a steel office: A1 and A2 carry the full title block, revision table and bill of materials; A3 and A4 carry a reduced title block and no bill of materials, because the part list is already in the drawing views.

Where the Layouts Live

Layout files are stored in the \attributes subfolder in the model folder, with a .lay extension, one file per custom layout.

That is fine while you are developing them and useless as a company standard. Copy the layout files to the project or firm folders defined by the XS_FIRM and XS_PROJECT advanced options, and every model picks them up.

Move the template and the layout together

A layout refers to table templates by name. Copying the .lay file to the firm folder without copying the title block template it points at gives you a layout that loads and a sheet with a missing table.
